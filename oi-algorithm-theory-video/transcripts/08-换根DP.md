# 第 8 集　换根 DP

**让每个点都当一次根**

## 问题：每个点的距离和

- `0:21` 一棵 8 个点的树，边长都是 1。对每个点 v，求 S(v) = v 到所有点的距离之和。
  - 板书：S(v) = Σ dist(v, u)，对每个 v 都要求
- `0:29` 一个点的 S 很好算：从它出发做一次 DFS。但对每个点都做一次是 O(n²)，n = 10⁶ 时不行。
  - 板书：朴素：n 次 DFS，O(n²)
- `0:40` 思路：先以 1 为根算出 S(1)，再想办法从 S(父亲) 一步推出 S(儿子)。

## 第一遍：向下汇总

- `0:51` 第一遍 DFS 算两样东西：子树大小 size[u]，以及 down[u] = u 到它子树里所有点的距离和。
  - 板书：size[u]：u 子树的点数
  - 板书：down[u] = Σ_{子树内 x} dist(u, x)
- `1:01` down 怎么合并？儿子 c 子树里的每个点，到 u 都比到 c 多走一步，一共多出 size[c]。
  - 板书：down[u] = Σ_c ( down[c] + size[c] )
- `1:11` 根 1 的 down 就是 S(1) = 12。

## 第二遍：把根挪到儿子

- `1:19` 现在把根从 u = 1 挪到儿子 c = 4。到每个点的距离怎么变？
- `1:26` 4 的子树里的 3 个点（青色）：从 4 出发比从 1 出发近 1 步。其余 5 个点（橙色）：要多走边 (1, 4)，远 1 步。
  - 板书：根 u → 儿子 c：c 子树里 size[c] 个点近 1，其余 n − size[c] 个点远 1
  - 板书：S(c) = S(u) − size[c] + (n − size[c])
- `1:38` 所以 S(4) = S(1) − 3 + 5 = 12 − 3 + 5 = 14。一步就算完。
- `1:44` 第二遍 DFS 从根往下，用这个式子把每个点的答案依次推出来。两遍都是 O(n)。
- `1:53` S 最小的是点 1（12）。每个值都可以用 BFS 核对。
- `1:59` 这个公式还说明：当 size[c] > n/2 时，把根移到 c 会让 S 变小。所以 S 最小的点就是树的重心。
  - 板书：size[c] > n/2 ⇒ 往 c 走更好 → 最优点是重心

## 换根的一般形式

- `2:13` 一般地，以 c 为根的答案由两部分拼成：c 自己子树里的信息 down[c]，和“c 子树以外”的信息 up[c]。
  - 板书：ans[c] = 合并( down[c], up[c] )
  - 板书：up[c]：从 c 往上看，树的其余部分的信息
- `2:25` up[c] 来自父亲 u：u 往上的部分 up[u]，加上 u 的其他儿子的子树。关键操作是“从 u 的总信息里去掉儿子 c 的贡献”。
  - 板书：关键：从 u 的信息里去掉儿子 c 的贡献
- `2:37` 距离和是加法，去掉一个儿子的贡献就是减法，所以很容易。但如果信息是最大值呢？最大值不能“减”。
  - 板书：加法：可减 ✓　最大值：不可减 ✗
- `2:49` 例：求每个点到最远点的距离（离心率）。down 部分是“向下最长的路” d1[u]。
- `2:58` 算 up[4]：要知道 1 的其他儿子方向最远能走多远。1 向下最长的路恰好经过 4（长度 3），去掉 4 之后要用次长的那条（经过 2，长度 2）。
  - 板书：最大值：同时记最长 d1[u] 和次长 d2[u]（以及最长来自哪个儿子）
  - 板书：up[c] = 1 + max( up[u], (c 是最长的来源 ? d2[u] : d1[u]) )
- `3:12` 所以 up[4] = 1 + max(up[1], d2[1]) = 1 + max(0, 2) = 3，离心率 = max(d1[4], up[4]) = max(2, 3) = 3。
- `3:23` 如果信息更复杂，可以对每个点的儿子做前缀合并和后缀合并：去掉第 i 个儿子 = 前 i−1 个的前缀 ⊕ 后面的后缀。只要求合并满足结合律。
  - 板书：一般方法：儿子的前缀合并 + 后缀合并，“挖掉”任意一个儿子

## 手推 / 建模题

- `3:42` 先别急着看答案：按暂停，在纸上推一推。
- `4:07` (1) c 子树里的 A[c] 个人各少走 1 步，其余 A − A[c] 个人各多走 1 步。
  - 板书：T(c) = T(u) − A[c] + (A − A[c]) = T(u) + A − 2A[c]
- `4:15` (2) 当 A[c] > A/2 时，挪到 c 会让 T 变小。所以最优点 v 满足：以 v 为根时，每个儿子子树里的人数都不超过 A/2。
  - 板书：最优点：每棵子树的人数 ≤ A/2（带权重心）
- `4:27` 这就是“带权重心”。换根公式不只是算答案的工具，它的形式本身就揭示了最优解的结构。
