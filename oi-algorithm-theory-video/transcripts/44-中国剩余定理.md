# 第 44 集　中国剩余定理

**把同余方程一个个合并**

## 模数两两互素：拼出来

- `0:25` 三个方程：x ≡ 2 (mod 3)，x ≡ 3 (mod 5)，x ≡ 2 (mod 7)。3、5、7 两两互素。
- `0:33` 思路：分别造三个数，第 i 个数“只管”第 i 个方程——模 mᵢ 余 1，模其他模数余 0。然后按 aᵢ 加权求和。
  - 板书：造 eᵢ：eᵢ ≡ 1 (mod mᵢ)，且被其他所有 mⱼ 整除
- `0:44` M = 3 × 5 × 7 = 105。Mᵢ = M/mᵢ 被其他模数整除；再乘上 Mᵢ 模 mᵢ 的逆元 tᵢ（互素所以存在），就让它模 mᵢ 余 1。
  - 板书：M = ∏mᵢ = 105；eᵢ = Mᵢ · (Mᵢ⁻¹ mod mᵢ)
- `0:56` 右边三列验证：e₁、e₂、e₃ 模 3、5、7 的余数排成单位矩阵——每个 eᵢ 只在自己的方程里是 1。
- `1:06` 于是 x = 2e₁ + 3e₂ + 2e₃ = 233，模 105 后得 x = 23。
  - 板书：x = Σ aᵢeᵢ mod M = 23

## 解在模 M 下唯一

- `1:16` 如果 x 和 x′ 都是解，那么每个 mᵢ 都整除 x − x′。mᵢ 两两互素，所以它们的乘积 M 也整除 x − x′。
  - 板书：两两互素：解在模 M = ∏mᵢ 下唯一
- `1:26` 所有解就是 23 + 105k。反过来，模 M 的每个余数都恰好对应一组 (x mod 3, x mod 5, x mod 7)——105 个余数和 3 × 5 × 7 种余数组合一一对应。

## 模数不互素：两个两个合并

- `1:44` 模数不互素时，逆元可能不存在，上面的构造失效。换个思路：先把前两个方程合并成一个，再和第三个合并……
  - 板书：一般情形：两个方程合并成一个，依次合并
- `1:57` 例：x ≡ 2 (mod 6)，x ≡ 8 (mod 10)。满足第一个的数是 2 + 6k，代入第二个：6k ≡ 6 (mod 10)。
- `2:07` 这是关于 k 的同余方程：有解 ⇔ g = gcd(6, 10) = 2 整除 6。约去 g 后用逆元解出 k ≡ 1 (mod 5)。
  - 板书：m₁k ≡ a₂ − a₁ (mod m₂)：有解 ⇔ gcd(m₁, m₂) | a₂ − a₁
- `2:17` 代回 x = 2 + 6·1 = 8。合并后的方程是 x ≡ 8 (mod 30)，新模数是 lcm(6, 10) = 30。
  - 板书：合并结果：x ≡ a₁ + m₁k (mod lcm(m₁, m₂))
- `2:25` 再和 x ≡ 3 (mod 7) 合并：8 + 30k ≡ 3 (mod 7)，解得 k ≡ 1，x ≡ 38 (mod 210)。依次合并就能处理任意多个方程。
- `2:37` 什么时候无解？例如 x ≡ 1 (mod 4) 和 x ≡ 2 (mod 6)：前者说 x 是奇数，后者说 x 是偶数。gcd(4, 6) = 2 不整除 2 − 1，正是这个矛盾。
  - 板书：例：x ≡ 1 (mod 4)、x ≡ 2 (mod 6) 无解（奇偶矛盾）
- `2:50` 实现时要小心溢出：k 先对 m₂/g 取模，模数一路乘到 lcm，中间乘法可能超过 64 位，需要用龟速乘或 128 位整数。
  - 板书：注意溢出：中间乘积可能超过 64 位

## 手推 / 建模题

- `3:07` 先别急着看答案：按暂停，在纸上推一推。
- `3:32` (1) 先合并前两个：3 + 4k ≡ 5 (mod 6)，即 4k ≡ 2 (mod 6)。gcd(4, 6) = 2 整除 2，约成 2k ≡ 1 (mod 3)，k ≡ 2，x ≡ 11 (mod 12)。
- `3:45` 再和 x ≡ 2 (mod 5) 合并：11 + 12k ≡ 2 (mod 5)，解得 k ≡ 3，x ≡ 47 (mod 60)。验算：47 除以 4、6、5 分别余 3、5、2。
  - 板书：(1) x ≡ 11 (mod 12) → x ≡ 47 (mod 60)
- `3:57` (2) 无解：x ≡ 3 (mod 4) 说明 x 是奇数，x ≡ 4 (mod 6) 说明 x 是偶数。用条件判断：gcd(4, 6) = 2 不整除 4 − 3 = 1。
  - 板书：(2) 无解：gcd(4, 6) ∤ 1
