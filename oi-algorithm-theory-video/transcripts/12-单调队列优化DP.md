## 问题：烽火传递

- `0:21` 一排 8 座烽火台，点亮第 i 座要花 cᵢ。要求任意连续 3 座里至少有一座被点亮。求最小总花费。
  - 板书：任意连续 m 座（m = 3）中至少点亮一座；求最小花费
- `0:32` 状态：f[i] = 第 i 座被点亮、并且前 i 座都满足要求时的最小花费。上一座被点亮的 j 必须离 i 不超过 m。
  - 板书：f[i] = cᵢ + min( f[j] )，i − m ≤ j ≤ i − 1
  - 板书：f[0] = 0（虚拟起点）；答案 = min f[n−m+1 .. n]
- `0:43` 直接算：每个 i 都要在长度为 m 的窗口里找最小值，O(nm)。n、m 都是 10⁵ 时就慢了。
  - 板书：朴素：每次扫窗口，O(nm)
- `0:53` 观察窗口：算 f[i] 时看 [i−m, i−1]，算 f[i+1] 时看 [i−m+1, i]。窗口的左右端点都只往右走。
  - 板书：窗口 [i−m, i−1] 的两端都单调右移

## 哪些候选永远没用

- `1:07` 设两个候选 j < j′ 都在窗口里，并且 f[j] ≥ f[j′]。
- `1:13` j 比 j′ 早离开窗口（更“老”），值又不比 j′ 小（不更好）。只要 j 还在窗口里，j′ 也一定在，而且至少一样好。
  - 板书：j < j′ 且 f[j] ≥ f[j′] → j 永远不会再是最优
- `1:26` 所以 j 可以直接扔掉，再也不会用到。这就是“过时又更差的候选永远没用”。
- `1:35` 扔掉所有这样的候选后，剩下的候选按下标从小到大排，f 值也严格从小到大。这个序列叫单调队列。
  - 板书：剩下的候选：下标递增，f 递增 → 单调队列
  - 板书：队首 = 窗口内最小值
- `1:46` 每来一个新的 i，做三件事：
  - 板书：① 队首过期（< i − m）就弹出
  - 板书：② 用队首算 f[i]
  - 板书：③ 从队尾弹出所有 f ≥ f[i] 的，再把 i 放进队尾

## 推一遍

  - 板书：队列里画的是下标（上）和 f 值（下）
  - 板书：① 队首过期（< i − m）就弹出
  - 板书：② 用队首算 f[i]
  - 板书：③ 队尾所有 f ≥ f[i] 的弹出，i 进队尾
- `2:02` i = 4：窗口是 [1, 3]。队首 0 已过期，弹出。用队首 2：f[4] = f[2] + c4 = 1 + 2 = 3。
- `2:11` 再看队尾：f[3] = 5 都 ≥ f[4] = 3，它们比 4 老又不比它好，弹出。
- `2:19` i = 6：窗口是 [3, 5]。队首 2 已过期，弹出。用队首 4：f[6] = f[4] + c6 = 3 + 1 = 4。
- `2:28` 再看队尾：f[5] = 5 都 ≥ f[6] = 4，它们比 6 老又不比它好，弹出。
- `2:36` 最后几座里至少有一座要亮：答案 = min(f[6..8]) = 4。
- `2:43` 每个下标恰好进队一次，至多出队一次，所以总共 O(n)。单次可能弹出很多个，但平摊下来每次 O(1)。

## 什么时候能用

- `2:58` 单调队列成立依赖两个条件。第一：窗口的左右端点都单调不减。被扔掉的候选永远不会再回到窗口里。
  - 板书：条件一：窗口两端单调移动（扔掉的不会再需要）
- `3:10` 如果某一步窗口的左端点往回缩了，一个早就被扔掉的老候选可能重新变成最优——但它已经不在队列里了。
- `3:21` 第二：要比较的量只和 j 有关。f[i] = (只和 i 有关的部分) + min (只和 j 有关的部分 h(j))，队列按 h(j) 维护。
  - 板书：条件二：f[i] = g(i) + min h(j)，h 只依赖 j
- `3:33` 例如 f[i] = min(f[j] + (i − j)·w)，展开是 i·w + min(f[j] − j·w)，h(j) = f[j] − j·w，可以用。
  - 板书：f[j] + (i − j)·w → i·w + (f[j] − j·w) ✓
- `3:44` 但 f[i] = min(f[j] + (sᵢ − sⱼ)²) 展开后有 −2sᵢsⱼ 这一项，同时依赖 i 和 j：对不同的 i，候选的优劣顺序会变，单调队列不再成立。
  - 板书：(sᵢ − sⱼ)² 含 sᵢsⱼ 交叉项 ✗ → 斜率优化（第 54 集）
- `3:58` 另外，多重背包按“体积除以 w 的余数”分组后，每组里的转移恰好是滑动窗口最值，也能用单调队列做到 O(nV)。

## 手推 / 建模题

- `4:14` 先别急着看答案：按暂停，在纸上推一推。
- `4:40` (a) 能：h(j) = f[j]，求最大值，队列里 f 值单调递减。
  - 板书：(a) ✓ h(j) = f[j]（单调递减队列）
- `4:46` (b) 能：3i 只和 i 有关，h(j) = f[j] − 2j。
  - 板书：(b) ✓ h(j) = f[j] − 2j
- `4:52` (c) 不能：j × i 是交叉项。i 变大时，j 大的候选“涨得更快”，优劣顺序会随 i 改变。这是斜率优化的形式。
  - 板书：(c) ✗ 交叉项 j·i → 斜率优化
- `5:04` (d) 不能直接用：绝对值按 aⱼ ≤ aᵢ 和 aⱼ > aᵢ 分成两种情况，候选要按 aⱼ 的大小分开处理（要用数据结构），不再是单纯按下标的窗口最值。
  - 板书：(d) ✗ 不能直接用：要按 aⱼ 分类，需要数据结构
