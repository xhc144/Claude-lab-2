## 问题与朴素 DP

- `0:27` 把序列 1, 1, 1, 1, 3, 4 切成若干段，每段的代价是（段内和）² + 10，求最小总代价。s 是前缀和。
  - 板书：f[i] = min_j f[j] + (sᵢ − sⱼ)² + M（M = 10）
- `0:38` f[i] = 前 i 个数的最小代价，枚举最后一段从 j + 1 到 i。每个 i 都要枚举所有 j：O(n²)。
- `0:47` 平方项把 i 和 j 搅在一起，没法直接用单调队列。先把它展开看看。

## 把 j 看成点，把 i 看成斜率

- `0:59` 展开：f[j] + sᵢ² − 2sᵢsⱼ + sⱼ² + M。和 j 无关的 sᵢ² + M 提出去，要最小化的是 (f[j] + sⱼ²) − 2sᵢ · sⱼ。
  - 板书：令 xⱼ = sⱼ，yⱼ = f[j] + sⱼ²，k = 2sᵢ
  - 板书：f[i] = min (yⱼ − k·xⱼ) + sᵢ² + M
- `1:10` 算 f[6] 时，每个 j 是平面上一个点 (xⱼ, yⱼ)，sᵢ = 11，斜率 k = 2sᵢ = 22。
- `1:19` yⱼ − k·xⱼ 就是“过点 j、斜率为 k 的直线”的纵截距。要它最小：拿一条斜率 22 的直线从下往上平移，最先碰到的点就是最优的 j。
  - 板书：最优 j = 斜率 k 的直线从下往上平移时最先碰到的点
- `1:32` 最先碰到的是 j = 5，截距 -60，所以 f[6] = -60 + 11² + 10 = 71。

## 只有下凸壳上的点可能最优

- `1:44` 不管斜率是多少，从下往上平移的直线最先碰到的，一定是这些点的“下凸壳”（绿色折线）上的点。凸壳上方的点永远不会被先碰到。
- `1:59` 比如点 j = 1 在 j = 0 和 j = 2 连线的上方：任何斜率下，两边至少有一个点比它先被碰到。可以直接删掉。
  - 板书：只保留下凸壳：相邻点连线的斜率递增
- `2:10` 下凸壳上相邻两点连线的斜率递增。斜率为 k 的直线最先碰到的点 j，满足：左边那段的斜率 ≤ k ≤ 右边那段的斜率。
  - 板书：最优点：左边线段斜率 ≤ k ≤ 右边线段斜率

## 斜率单调：单调队列维护凸壳

- `2:27` 这里 a 都是正数，所以新加入的点 x 坐标递增；查询的斜率 k = 2sᵢ 也递增。两个单调性让我们可以用一个双端队列。
  - 板书：x 递增：新点从队尾加入；k 递增：最优点只会往右移
- `2:40` 队首：若队首两点连线的斜率 ≤ k，队首以后都不会再是最优（k 只会更大），弹掉。队尾：加入新点前，若队尾那个点在“倒数第二个点与新点”连线的上方，弹掉。
  - 板书：队首：斜率(q₁, q₂) ≤ k 则弹出；队尾：不凸则弹出
- `2:57` i = 2：新点 2 加入时，点 1 在点 0 和点 2 连线的上方（不凸），从队尾弹掉。
- `3:05` 每个点进队一次、出队至多一次，均摊 O(n)。最终答案 f[6] = 71。
  - 板书：总 O(n)；答案 f[6] = 71

## 手推 / 建模题

- `3:18` 先别急着看答案：按暂停，在纸上推一推。
- `3:43` (1) xⱼ = sⱼ，yⱼ = f[j] + sⱼ²，k = 2sᵢ。求的是截距的最小值，直线从下往上碰，所以是下凸壳；求最大值时就换成上凸壳。
  - 板书：(1) x = sⱼ，y = f[j] + sⱼ²，k = 2sᵢ；求最小 → 下凸壳
- `3:56` (2) k 不再递增：最优点不一定往右走，不能弹队首，改成在凸壳上二分斜率。x 不再递增：新点可能插在中间，单调队列维护不了，要用平衡树、CDQ 分治或李超线段树。
  - 板书：(2) k 无序：凸壳上二分；x 无序：平衡树 / CDQ / 李超树
