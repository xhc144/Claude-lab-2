# 朗兰兹纲领 · 介绍视频

一段约 3 分半钟的中文科普短片，介绍朗兰兹纲领（Langlands Program）。旁白用**通义千问 Qwen3-TTS**（阿里云百炼 DashScope）合成，
画面和配乐全部由 Python 程序生成，没有用到任何素材文件。

成品：`langlands.mp4`（1920×1080，30fps，H.264 + AAC，响度 −14 LUFS）。

## 内容

| 段落 | 讲什么 |
| --- | --- |
| 序章 · 1967 | 朗兰兹给韦伊的 17 页手写信，和那句「我相信您手边一定有个废纸篓」 |
| 标题 | 朗兰兹纲领 · 数学的大统一理论 |
| 两片大陆 | 数论（乌拉姆螺旋里的质数）和调和分析（波），以及连接它们的桥 |
| 一个具体的例子 | 椭圆曲线 y² + y = x³ − x² 在模 p 下的解数，和模形式 q∏(1−qⁿ)²(1−q¹¹ⁿ)² 的系数逐项对上 |
| 模性 | 怀尔斯、费马大定理，以及「冰山一角」 |
| 纲领 | 伽罗瓦表示 ↔ 自守表示、L 函数这个「共同的指纹」、函子性原理 |
| 远征 | 德林费尔德、怀尔斯、拉福格、吴宝珠、朗兰兹获阿贝尔奖、2024 年几何朗兰兹猜想的证明、物理里的电磁对偶 |
| 尾声 | 「同一个真理的不同译本」，以及那封没被扔进废纸篓的信 |

例子里的数字是真算出来的：`mathdata.py` 对 10000 以内全部 1229 个质数计算了曲线在 𝔽ₚ 上的解数 Nₚ 和模形式的系数 aₚ，
逐一验证 p − Nₚ = aₚ，画面上「1,229 / 1,229」就来自这里。

## 声音

- 旁白：Qwen3-TTS（`qwen3-tts-flash`），音色 **Kai**——低沉（基频约 100 Hz）、有磁性，预告片式的沉稳旁白。
  试过 **Ryan**，戏剧张力很强，但千问语音识别给几乎每一句都打上「愤怒」的情绪标签，听感偏吼，就换掉了。
- 信件原文：音色 **Ethan**，后期加了带通、轻微失真和底噪，像一段老录音，和旁白区分开。
- 质检：`check_tts.py` 用千问语音识别（`qwen3-asr-flash`）把每一句转写回文字和原稿比对，并给出情绪标签；
  读得不好的句子在 `narration.py` 里给它加 `take=1` 换一版重新合成。成片混音后也用同样的方法抽查过，旁白在配乐下都能被正确识别。
- 配乐和音效（`audio.py`，纯 numpy 合成）：开场的钟表滴答和管风琴、标题处的 Braam 冲击、例子部分 120 BPM 的脉冲贝斯、
  纲领部分的和弦铺底与太鼓、结尾落在 D 大调。旁白说话时音乐自动压低（侧链闪避）。

## 自己生成一遍

```bash
pip install skia-python numpy scipy matplotlib requests
# skia-python 需要 libEGL：Debian/Ubuntu 上 apt-get install libegl1
export DASHSCOPE_API_KEY=sk-...        # 阿里云百炼的 API Key（北京地域）
python make.py                          # 字体 → 语音 → 时间线 → 配乐 → 并行渲染 → build/langlands.mp4
python make.py --stills 34.5,96,146     # 只渲染几个时刻的静帧，调画面用
python make.py --audio                  # 只重新生成音轨
python check_tts.py                     # 用语音识别核对每一句旁白
```

可以用环境变量换音色：`QWEN_TTS_VOICE`（旁白，默认 Kai）、`QWEN_TTS_QUOTE_VOICE`（念信，默认 Ethan）、`QWEN_TTS_MODEL`。
语音按（模型、音色、文字）缓存在 `build/tts/`，只改了哪句就只重新合成哪句。

## 文件

| 文件 | 作用 |
| --- | --- |
| `narration.py` | 旁白稿：每句的朗读文字、字幕、停顿 |
| `tts.py` | 调千问 TTS 合成语音并缓存 |
| `check_tts.py` | 用千问语音识别核对合成结果 |
| `timeline.py` | 按每句的实际时长排出时间线 |
| `cues.py` | 画面事件和音效共用的时间表（冲击、提示音、镜头移动……） |
| `mathdata.py` | 椭圆曲线解数和模形式系数的真实计算 |
| `render.py` | skia 逐帧绘制画面（辉光、故障效果、庞加莱圆盘上的模群镶嵌……） |
| `audio.py` | 配乐、音效、旁白处理和混音 |
| `fonts.py` | 下载思源宋体/黑体、Orbitron、Rajdhani |
| `make.py` | 一键生成 |

## 史实与数学说明

- 信写于 1967 年 1 月，17 页手写；「废纸篓」那句出自随信附上的短笺（英文原文见画面）。朗兰兹生于 1936 年，当时 30 岁。
- 「一大类椭圆曲线」指半稳定椭圆曲线（怀尔斯 1994 年，部分工作与泰勒合作）；全部椭圆曲线的模性在 2001 年由 Breuil、Conrad、Diamond、Taylor 完成。
- 菲尔兹奖：德林费尔德 1990、洛朗·拉福格 2002、吴宝珠 2010；朗兰兹 2018 年获阿贝尔奖。
- 2024 年，盖茨戈里（Gaitsgory）、拉斯金（Raskin）等九位数学家在一系列论文中证明了几何朗兰兹猜想，总篇幅近千页。
- 物理联系指 Kapustin–Witten（2006）：四维 N=4 超对称杨–米尔斯理论的 S-对偶（电磁对偶）与几何朗兰兹对应。
