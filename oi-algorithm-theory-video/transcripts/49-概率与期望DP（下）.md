## 原地不动：解一个方程

- `0:23` 掷一个骰子，直到掷出 6 为止，期望掷几次？设答案为 E。
- `0:30` 掷一次后：1/6 的概率结束；5/6 的概率回到原来的状态——而且“从这里出发还要多少次”和刚才一模一样，还是 E。
  - 板书：E = 1 + (5/6)·E + (1/6)·0
- `0:43` 于是 E = 1 + (5/6)E。状态指向自己，不能“先算后面再算前面”，但可以把 E 当未知数解方程：E/6 = 1，E = 6。
  - 板书：E = 6；一般地，成功概率 p 的几何分布期望 1/p
- `0:55` 一般地，每次成功概率为 p，期望 1/p 次。带环的期望 DP，本质上就是解一个线性方程组。
  - 板书：带环：状态的期望满足线性方程组

## 链上的随机游走：递推消元

- `1:10` 点 0～4 排成一条链。在 0 只能往右；在中间的点，各以 1/2 的概率往左或往右。从 0 出发走到 4，期望几步？
- `1:22` E[i] = 1 + ½E[i − 1] + ½E[i + 1]：每个方程同时用到左右两边，没有可以“先算”的方向。直接高斯消元是 O(n³)，可链的结构更简单。
  - 板书：E[i] = 1 + ½E[i − 1] + ½E[i + 1]：左右互相依赖
- `1:36` 换个状态：设 dᵢ = 从 i 出发、第一次到达 i + 1 的期望步数。走到 n 必须依次跨过每一条边，所以答案 = d₀ + d₁ + … + dₙ₋₁。
  - 板书：dᵢ = 从 i 第一次走到 i + 1 的期望步数；答案 = Σdᵢ
- `1:48` d₀ = 1：在 0 只能往右。
- `1:52` 在 i（i ≥ 1）：走一步，1/2 直接到 i + 1；1/2 退到 i − 1，要先花 dᵢ₋₁ 回到 i，再花 dᵢ 到 i + 1。所以 dᵢ = 1 + ½(dᵢ₋₁ + dᵢ)，即 dᵢ = dᵢ₋₁ + 2。
  - 板书：dᵢ = 1 + ½(dᵢ₋₁ + dᵢ) ⇒ dᵢ = dᵢ₋₁ + 2
- `2:06` dᵢ = 2i + 1，答案 = 1 + 3 + 5 + 7 = 16 = 4²。一般地从 0 走到 n 期望 n² 步。
  - 板书：答案 Σ(2i + 1) = n²（这里 16；随机模拟 2 万次平均 16.01）
- `2:14` 技巧在于：每个未知数只和相邻的有关时，可以把 E[i] 表示成“下一个未知数的一次函数”，一路代下去，O(n) 消元。树上也可以这样做。
  - 板书：链、树上：用相邻未知数表示，逐个代入，O(n) 消元

## 收集优惠券

- `2:32` 每次随机得到 4 种卡片中的一种（等概率），集齐所有种类期望要抽几次？
- `2:41` 按“已经集到几种”分段。已有 k 种时，抽到新卡的概率是 (n − k)/n——这一段就是“直到成功”的几何分布，期望 n/(n − k) 次。
  - 板书：已有 k 种：下一种新卡期望 n/(n − k) 次
- `2:54` 由线性性，总期望 = 各段之和 = 1 + 4/3 + 2 + 4 = 25/3 ≈ 8.33 次。
  - 板书：总期望 n·(1 + 1/2 + … + 1/n) = n·Hₙ；n = 4 时 25/3
- `3:02` 越到后面越难：最后一种平均要 n 次。总体约 n ln n。注意这里没解方程——把过程切成几段几何分布，用线性性加起来就行。
