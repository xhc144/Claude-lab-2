**矩形面积并**

## 问题与扫描的想法

- `0:20` 三个矩形互相重叠。求它们的并的面积（重叠的部分只算一次）。
  - 板书：求矩形并的面积（重叠只算一次）
- `0:28` 想象一条竖直的线从左往右扫过去。在两个相邻的“事件横坐标”之间，竖线被矩形盖住的总长度 L 不变。
  - 板书：相邻事件之间，竖线上被覆盖的长度 L 不变
- `0:40` 所以面积 = Σ L × Δx：把图形切成一条条竖着的长条，每条是一个矩形。
  - 板书：面积 = Σ L × Δx
- `0:48` 事件：矩形的左边界让区间 [y1, y2) 覆盖次数 +1，右边界让它 −1。要维护的是：一堆可增可删的 y 区间，它们的并有多长。
  - 板书：左边界：[y1, y2) 覆盖 +1；右边界：−1
  - 板书：需要：动态维护区间并的长度 → 线段树

## 线段树里存什么

- `1:05` 先离散化 y 坐标：0, 1, 2, 3, 5。相邻两个 y 之间是一个“基本段”，线段树的叶子对应基本段。
  - 板书：叶子 = 相邻两个 y 之间的基本段
- `1:15` 每个结点存两个量：cnt = 有几个矩形“恰好在这个结点上”整段覆盖了它；L = 这个结点的范围里被覆盖的总长度。
  - 板书：cnt：整段覆盖本结点（在本结点打上）的矩形数
  - 板书：L：本结点范围内被覆盖的长度
- `1:27` L 怎么算？如果 cnt > 0，整段都被盖住，L = 区间长度；否则 L = 两个儿子的 L 之和（叶子则为 0）。
  - 板书：cnt > 0：L = 区间长；否则 L = 左.L + 右.L
- `1:38` 这里有个特别之处：cnt 从来不下传。一个矩形加入时把 [y1, y2) 拆成若干结点、在这些结点上 +1；删除时拆出的是完全相同的结点，−1 正好抵消。
  - 板书：cnt 不下传：加和删拆出同一组结点，正好抵消
- `1:54` 所以 cnt 不会变成负数，也不会被“错误地遗留”。而询问只看根的 L，从来不需要往下走。这叫“标记永久化”。

## 扫一遍

- `2:11` x = 1：矩形 1 的左边界，区间 [1, 3) 覆盖 +1。拆成结点 [1,2)、[2,3)。根的 L 变成 2。
- `2:21` x = 2：矩形 2 的左边界，区间 [2, 5) 覆盖 +1。拆成结点 [2,5)。根的 L 变成 4。
- `2:30` x = 4：矩形 1 的右边界，区间 [1, 3) 覆盖 −1。拆成结点 [1,2)、[2,3)。根的 L 变成 3。
- `2:39` 扫完：面积 = 20。每一段长条的面积是“上一事件后根的 L”乘以两个事件的横坐标差，逐段累加。直接数格子也是 20。
- `2:52` 每个事件在线段树上 O(log n)，事件 2n 个，加上排序，总共 O(n log n)。

## 手推 / 建模题

- `3:06` 先别急着看答案：按暂停，在纸上推一推。
- `3:31` 要求覆盖 ≥ 2 次的长度，记作 L2；同时还需要覆盖 ≥ 1 次的长度 L1（就是原来的 L）。
  - 板书：存 cnt、L1（≥1 次）、L2（≥2 次）
- `3:40` cnt ≥ 2：本结点整段已被盖了两次，L2 = 区间长。
  - 板书：cnt ≥ 2：L2 = 区间长
- `3:47` cnt = 1：本结点已经盖了一次，儿子里只要再被盖过一次就够两次，所以 L2 = 左.L1 + 右.L1（叶子为 0）。
  - 板书：cnt = 1：L2 = 左.L1 + 右.L1
- `3:58` cnt = 0：两次都得来自下面，L2 = 左.L2 + 右.L2。
  - 板书：cnt = 0：L2 = 左.L2 + 右.L2
- `4:04` 关键：本结点的 cnt 会“抬高”儿子信息的含义。这个设计又是“缺什么补什么”——为了算 L2，需要儿子的 L1。
