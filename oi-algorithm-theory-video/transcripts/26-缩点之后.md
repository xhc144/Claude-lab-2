## 问题：有环的图上取点权

- `0:24` 还是上一集的图，每个点有一个权值。可以从任意点出发，沿边随便走（点、边都能重复经过），每个点的权值只算一次。
  - 板书：点权只算一次；可重复走；求最大总和
- `0:37` 如果图没有环，就是 DAG 上的最长路：按拓扑序 DP。可现在有环，DP 找不到计算顺序。
  - 板书：有环 → 没有拓扑序，DP 不能直接做

## 缩点：分量里的点可以全拿

- `0:51` 关键观察：一旦进入一个强连通分量，就能把分量里的点全部走一遍再出来——它们两两可达。
  - 板书：进入一个 SCC → 可以拿到其中所有点权
- `1:02` 所以把每个分量“缩”成一个点，权值是分量内点权之和。分量之间的边保留，分量内部的边去掉。
  - 板书：缩点：每个 SCC → 一个点，权值 = 分量内点权之和
- `1:13` 缩完以后的图一定没有环。如果分量 A、B 之间有环，A 能到 B、B 也能到 A，它们里的点就全都互相可达，本该是同一个分量。
  - 板书：缩点图是 DAG：分量间若有环，它们本应合并

## 在 DAG 上 DP

- `1:29` 在 DAG 上：f[c] = 从分量 c 出发能拿到的最大总和 = 权(c) + max(f[后继])。要先算后继，再算自己。
  - 板书：f[c] = 权(c) + max f[后继]（没有后继则为权(c)）
- `1:40` 顺序从哪来？Tarjan 弹出分量的顺序恰好是“逆拓扑序”：一个分量被弹出时，它能到达的分量都已经先被弹出了。
  - 板书：Tarjan 弹出顺序 = 逆拓扑序：按弹出顺序算 f 即可
- `1:53` 最大值 f = 20：从 {1,2,3} 出发，走到 {9}，再到 {7,8}。比走 {4,5,6} 那条路（6 + 7 + 6 = 19）多 1。
- `2:04` 整个过程：Tarjan O(n + m)，建缩点图 O(n + m)，DAG 上 DP O(n + m)。
- `2:12` 这个套路很通用：有环的图上做 DP，先缩点变成 DAG。只要“在一个分量里可以随便绕”这件事对问题成立。
  - 板书：通用套路：有环 → 缩点成 DAG → 按拓扑序 DP

## 应用：被所有点到达的点

- `2:28` 另一个经典问题：有多少个点，能被其他所有点到达？（“受欢迎的牛”）
  - 板书：问：多少个点能被所有其他点到达？
- `2:37` 缩点后看出度为 0 的分量（“汇点”）。DAG 至少有一个汇点：从任意点一直往前走，因为没有环，最终一定停在汇点。
- `2:50` 如果汇点只有一个，那么任何点往前走都会停在它那里——它里面的每个点都能被所有点到达，答案是它的大小。
  - 板书：只有一个汇点分量：答案 = 它的大小
- `3:02` 如果有两个汇点（比如去掉 c→d，c 也成了汇点），它们互相到不了，任何点都不可能被所有点到达，答案是 0。
  - 板书：两个及以上汇点：答案 = 0

## 手推 / 建模题

- `3:18` 先别急着看答案：按暂停，在纸上推一推。
- `3:44` (1) 1、2 互相可达；3→4→5→3 是一个环；6 单独一个。分量：{1,2}、{3,4,5}、{6}。缩点后：{1,2} → {3,4,5} ← {6}。
  - 板书：(1) {1,2}、{3,4,5}、{6}；DAG：{1,2} → {3,4,5} ← {6}
- `3:57` (2) 出度为 0 的分量只有 {3,4,5}，所以 3、4、5 都能被所有点到达，答案是 3。
  - 板书：(2) 唯一汇点 {3,4,5} → 答案 3
