## 周期：错开 p 位还能对上

- `0:23` 如果对所有能比较的位置都有 s[i] = s[i + p]，就说 p 是 s 的一个周期。直观地说：把 s 复制一份右移 p 位，重叠部分完全一样。
  - 板书：周期 p：s[i] = s[i + p] 对所有 1 ≤ i ≤ n − p 成立
- `0:36` p = 1：第 1 位 a 对着第 2 位 b，不一样（红色），1 不是周期。
- `0:43` p = 2：也有对不上的位置，2 不是周期。
- `0:49` p = 3：重叠的 5 个位置全部相同，3 是周期。s 就是 abc 一直重复，最后一段没写完。
  - 板书：abcabcab 的周期：3、6、8（n = 8 总是周期）

## 周期 ⇔ border

- `1:02` 再看 p = 3 时的重叠部分：上面一行是 s 的后 5 个字符，下面一行是 s 的前 5 个字符。
- `1:12` “错开 3 位重叠部分相同”就是“长度 5 的前缀等于长度 5 的后缀”，即 s 有一个长度为 5 的 border。
  - 板书：p 是周期 ⇔ s 有长度为 n − p 的 border
- `1:23` 所以周期和 border 一一对应：p ↔ n − p。最长的 border 对应最短的周期：最小周期 = n − π[n] = 8 − 5 = 3。
  - 板书：最小周期 = n − π[n]；全部周期 = n − (失配链上的每个 border)
- `1:34` 沿失配链列出全部 border：5、2，对应的周期就是 3、6，再加上 n = 8 本身。

## 两个周期的差还是周期

- `1:46` 什么时候 s 能写成某个串的整数次重复（循环节）？先证明一个工具：如果 p < q 都是周期，并且 p + q ≤ n，那么 q − p 也是周期。
  - 板书：引理：p < q 是周期，p + q ≤ n ⇒ q − p 是周期
- `2:00` 情形一：i + q ≤ n。先往右跳 q：s[i] = s[i + q]；再往左跳 p：s[i + q] = s[i + q − p]。合起来就是 s[i] = s[i + q − p]。
- `2:12` 情形二：i + q > n，往右跳不了 q。但这时 i > n − q ≥ p，可以先往左跳 p：s[i] = s[i − p]；再往右跳 q：s[i − p] = s[i − p + q]。
- `2:24` 两种情形都得到 s[i] = s[i + (q − p)]。条件 p + q ≤ n 保证了两种情形总有一种能跳。
- `2:34` 像辗转相减一样反复用这个引理，就得到：gcd(p, q) 也是周期（弱周期引理）。
  - 板书：反复相减 ⇒ gcd(p, q) 也是周期

## 什么时候是整数次重复

- `2:47` 设 s = t 重复 k 次（k ≥ 2），|t| = q。那么 q 是周期且 q 整除 n。最小周期 p ≤ q，而 q ≤ n/2，所以 p + q ≤ n。
- `2:58` 由引理，gcd(p, q) 也是周期；p 是最小的，只能 gcd(p, q) = p，即 p 整除 q，从而 p 整除 n。
  - 板书：s 是某个串的 k 次重复（k ≥ 2）⇔ p = n − π[n] < n 且 p | n
- `3:08` 所以判断只看最小周期：p 整除 n（且 p < n）就是整数次重复，循环节是前 p 个字符；否则不是。
- `3:18` 对 aabaabaab 的每个前缀判断：i = 2、6、9 时 i − π[i] 整除 i，分别是 a 重复 2 次、aab 重复 2 次、aab 重复 3 次。
  - 板书：每个前缀 i：i − π[i] 整除 i 且 π[i] > 0 ⇒ 重复 i/(i − π[i]) 次

## 手推 / 建模题

- `3:34` 先别急着看答案：按暂停，在纸上推一推。
- `4:00` (1) π[8] = 5，失配链给出全部 border：5、2、1。周期是 3、6、7 和 8。
  - 板书：(1) 周期：3、6、7、8
- `4:08` (2) 最小周期 p = 3，8 不是 3 的倍数，所以不是整数次重复。
  - 板书：(2) p = 3 不整除 8：不是
- `4:15` (3) 补到 p 的倍数最省：补 1 个字符，变成 aabaabaab = aab 重复 3 次。
- `4:23` 为什么不会更少？补完后的串以 s 开头，它的最小周期 p′ 也必须是 s 的周期（3、6、7、8，或者比 8 大），长度又至少是 2p′。逐个比较，p′ = 3 时补到 9 最短。
  - 板书：(3) 补 1 个 → aabaabaab
