## 一个询问：二分答案

- `0:27` 询问：[2, 6] 里第 3 小的数是多少？区间里是 1, 4, 2, 7, 3，排好序第 3 个是 3。
  - 板书：询问 [l, r] 第 k 小（例：[2, 6] 第 3 小）
- `0:35` 不排序也能求：猜一个答案 mid，数一数区间里 ≤ mid 的有几个，记作 cnt。cnt ≥ k 说明答案 ≤ mid，否则答案 > mid。
  - 板书：猜 mid，数 cnt = #{ x ≤ mid }：cnt ≥ k ⇔ 答案 ≤ mid
- `0:48` mid = 4：cnt = 4 ≥ 3，第 3 小不会超过 4，范围缩到 [1, 4]。
- `0:55` mid = 2：cnt = 2 < 3，≤ 2 的数不够 3 个，答案 > 2，范围缩到 [3, 4]。
- `1:02` mid = 3：cnt = 3 ≥ 3，第 3 小不会超过 3，范围缩到 [3, 3]。
- `1:09` 范围只剩 3，答案就是 3。值域大小为 V，要检查 log V 次，每次扫一遍区间。
- `1:18` q 个询问各二分一遍：O(q · n log V)。慢在每个询问都要单独检查，而不同询问的检查其实在做同一件事。
  - 板书：单独二分：每个询问 O(n log V)，共 O(q · n log V)

## 所有询问一起二分

- `1:33` 把所有询问放在一起：开始时它们的答案范围都是 [1, 8]，猜的 mid 也都是 4。“哪些数 ≤ 4”对每个询问都一样，只需要准备一次。
  - 板书：所有询问共用 mid：把 ≤ mid 的数按下标放进树状数组
- `1:47` mid = 4：把值 ≤ 4 的数（绿色）按下标加进树状数组。之后每个询问只要查一次区间和，就知道 [l, r] 里有几个 ≤ 4。
- `2:00` 注意 Q2：[1, 8] 里 ≤ 4 的已经有 4 个，答案是剩下的数里第 6 − 4 = 2 小。往右走时，k 要减去左边已经数过的个数。
  - 板书：去右边：k ← k − cnt（≤ mid 的那些数以后不再出现）
- `2:12` 然后把元素和询问一起分成两组：值 ≤ 4 的数和答案在 [1, 4] 的询问去左边，其余去右边。两组互不相干，各自递归。
  - 板书：元素按值分、询问按答案范围分，两组分别递归
- `2:24` 左组只剩值在 [1, 4] 的数，右组只剩 [5, 8] 的数。下一层两组各自取自己的 mid，再做一遍同样的事。
- `2:35` 范围 [1, 4]，mid = 2，加入值 ≤ 2 的 2 个数。Q1 数到 2 < 3，去 [3, 4]，k = 1；Q3 数到 1 < 2，去 [3, 4]，k = 1。
- `2:47` 范围 [5, 8]，mid = 6，加入值 ≤ 6 的 2 个数。Q2 数到 2 ≥ 2，去 [5, 6]；Q4 数到 1 ≥ 1，去 [5, 6]。
- `2:57` 范围 [3, 4]，mid = 3，加入值 ≤ 3 的 1 个数。Q1 数到 1 ≥ 1，去 [3, 3]；Q3 数到 1 ≥ 1，去 [3, 3]。
- `3:07` 范围 [5, 6]，mid = 5，加入值 ≤ 5 的 1 个数。Q2 数到 1 < 2，去 [6, 6]，k = 1；Q4 数到 1 ≥ 1，去 [5, 5]。
- `3:18` 所有范围都缩成一个数：Q1 = 3，Q2 = 6，Q3 = 3，Q4 = 5。和直接排序求出的结果一致。
  - 板书：答案：Q1 = 3，Q2 = 6，Q3 = 3，Q4 = 5

## 为什么快：每一层只看一遍

- `3:32` 看值域那棵树：同一层的各组，值域互不重叠。每个数只落在一组里，每个询问也只落在一组里。
  - 板书：同一层：每个数、每个询问只在一组里
- `3:43` 一组的花费是 O((组里的数 + 组里的询问) · log n)：插入树状数组、查询区间和。所以一层合计 O((n + q) log n)。
- `3:55` 值域每层减半，一共 log V 层。总复杂度 O((n + q) log n log V)，和询问个数基本无关地“摊”掉了检查。
  - 板书：每层 O((n + q) log n)，共 log V 层 → O((n + q) log n log V)
- `4:06` 细节：一组做完要把树状数组还原。不能整个清空（那是 O(n)，组数一多就超时），只撤销自己加进去的那些位置。
  - 板书：还原树状数组：只撤销本组加过的位置

## 什么时候能整体二分

- `4:23` 条件一：每个询问的答案单独可以二分——“答案 ≤ mid”这件事关于 mid 单调。
  - 板书：① 每个询问单独可二分（判定单调）
- `4:32` 条件二：同一个 mid 的判定可以批量做——先把“贡献”一次性加进数据结构，再让每个询问各查一次。
  - 板书：② 判定可以批量：先加贡献，询问各查一次
- `4:43` 条件三：贡献可以拆开、可以累加。去右边时 k 减去左边的计数，靠的就是“≤ mid 的贡献”可以单独算出来再减掉。
  - 板书：③ 贡献可累加：去右边时减掉左半的贡献
- `4:56` 带修改的第 k 小也能做：把“改一个数”拆成“删掉旧值、加入新值”两个事件，和询问一起按时间排好，按值分组时事件也分到两边。
  - 板书：带修改：修改拆成删旧值 + 加新值，按时间顺序一起分组
- `5:11` 和 CDQ 分治对照：CDQ 对“时间”分治、算左半对右半的贡献；整体二分对“答案”分治、把询问和贡献按答案分到两边。

## 手推 / 建模题

- `5:28` 先别急着看答案：按暂停，在纸上推一推。
- `5:53` (1) 答案是天数，可以二分：做完前 mid 天的操作后，第 i 个人的累计值 ≥ pᵢ，答案就 ≤ mid。累计值随天数只增不减，判定单调。
  - 板书：(1) 二分天数 mid：前 mid 天做完后累计 ≥ pᵢ？（单调）
- `6:07` (2) mid 是天数。一组的答案范围是 [L, R]：把第 L～mid 天的区间加做进树状数组（区间加、单点查），每个人查自己的累计 s。
- `6:21` s ≥ p 的人去左边 [L, mid]；其余的人把目标减成 p − s，去右边 [mid + 1, R]——和第 k 小里的 k − cnt 是一回事。
  - 板书：(2) 组 [L, R]：做第 L～mid 天；s ≥ p 去左，否则 p ← p − s 去右
- `6:32` 答案范围设成 [1, m + 1]，落在 m + 1 的就是达不到。复杂度 O((n + m) log n log m)。
  - 板书：答案范围 [1, m + 1]：m + 1 表示 −1；O((n + m) log n log m)
