# 数理积木速查

按“数学积木”格式（条件 → 具体操作/核心式 → 结果，红框只圈关键部分）整理的数学与物理速查，共 13 章、2027 条，难度对标 MIT 本科高年级课程。
版式沿用用户样张《粒度与重点样张》：ctexart + 蓝色结论框 + 红色局部重点框。

| 章 | 条数 | 章 | 条数 |
| --- | --- | --- | --- |
| 1 分析代数 | 475 | 8 电磁学 | 76 |
| 2 几何拓扑 | 228 | 9 近代物理 | 73 |
| 3 概率论 | 227 | 10 光学波动 | 73 |
| 4 数值统计 | 225 | 11 电磁实验 | 67 |
| 5 应用数学 | 232 | 12 数据分析 | 70 |
| 6 力学 | 83 | 13 综合应用 | 73 |
| 7 四大力学 | 125 | | |

- `main.tex`：主文件，按 `\续{文件名}` 依次读入各节。
- `chapters/`：各章各节。`01-…`、`02-…` 等为原稿，`01b`、`01c`… 为续写的小节（每个文件一个 `\subsection`）。
- `核验/`：15 个符号与数值核验脚本（sympy、numpy、scipy、mpmath）、结果 JSON，以及《核验记录》（各章条数、每个脚本覆盖哪些小节、没有做机械核验的条目、撰写中发现并订正的问题）。
- `数理积木速查.pdf`：编译好的成品（约 375 页）。

内容依据标准教材与课程知识整理，不是对某份资料的抽取；各节末列参考书目与 MIT 课程号，不编造页码。

## 重新生成

```sh
xelatex main.tex && xelatex main.tex      # 两遍生成目录
cp main.pdf 数理积木速查.pdf
cd 核验 && python3 verify_math9.py        # 任一核验脚本，结果写入同名 .json
```

编译中间文件（`main.aux`、`main.log`、`main.toc`、`main.out`、`main.pdf`）不提交。
