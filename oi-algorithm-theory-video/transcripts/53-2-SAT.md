## 子句变成蕴含

- `0:30` 3 个变量 x₁、x₂、x₃，4 条子句，每条形如 (a ∨ b)：a、b 是某个变量或它的否定，至少有一个为真。
  - 板书：2-SAT：每条子句 (a ∨ b)，两个文字至少一个为真
- `0:41` 关键转化：(a ∨ b) 等价于两句“如果……就……”：如果 a 为假，b 必须为真；如果 b 为假，a 必须为真。
  - 板书：(a ∨ b) ⇔ (¬a → b) 且 (¬b → a)
- `0:52` 每个变量的“真”和“假”各建一个点，共 2n 个点；每条子句连两条有向边。这张图叫蕴含图：沿着边走，就是“一旦选了它，后面这些都被迫成立”。

- `1:12` 上面一排是 xᵢ 为真，下面一排是 xᵢ 为假（¬xᵢ 为真）。
- `1:19` 如果从 x 能走到 ¬x，同时从 ¬x 也能走到 x，那么 x 取真取假都会推出矛盾——无解。也就是 x 和 ¬x 在同一个强连通分量里。

## 按拓扑序给出一组解

- `1:53` 缩点后得到一个 DAG。对每个变量，比较 xᵢ 和 ¬xᵢ 所在分量的拓扑序：选拓扑序靠后的那个为真。
  - 板书：x 的分量在拓扑序里比 ¬x 靠后 ⇒ x 取真
- `2:03` 为什么？选一个文字为真，会迫使它能走到的所有文字为真。选靠后的那个，它不可能走到靠前的“自己的否定”，就不会自相矛盾。
- `2:18` Tarjan 有个方便的性质：先找到（编号小）的分量在拓扑序里靠后。所以只要比较编号：分量编号小的那个取真。
  - 板书：Tarjan 的分量编号 = 逆拓扑序：编号小的取真
- `2:30` 结果：x1 = 假，x2 = 真，x3 = 假。代回四条子句检验，全部满足。
  - 板书：解：x1 = 假，x2 = 真，x3 = 假
- `2:38` 整体复杂度 O(n + m)：建图、一次 Tarjan、一次比较。“至多选一个”“必须选”这类限制也都能写成子句：x 必选就是 (x ∨ x)，也就是边 ¬x → x。
  - 板书：必选 x：(x ∨ x)，即 ¬x → x；总 O(n + m)
