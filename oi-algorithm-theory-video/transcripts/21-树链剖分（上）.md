## 把路径变成几段区间

- `0:23` 上一集的树上差分只能离线。现在要求：路径加 x、路径求和，随时交替出现，每次都要快。
  - 板书：目标：在线的路径修改 / 路径查询
- `0:34` 线段树擅长的是数组上的区间。如果能把树拆成若干条“链”，每条链在某个数组里连续，那么一条路径 = 几段区间。
  - 板书：想法：拆成链，每条链在数组里连续 → 路径 = 几段区间
- `0:46` 关键是路径经过的链要少。怎么拆，才能保证任意路径只经过 O(log n) 条链？

## 重儿子与轻边

- `0:59` 先算出每个点的子树大小 size。每个点选子树最大的那个儿子作为“重儿子”，连向它的边是重边，其余是轻边。
  - 板书：重儿子 = size 最大的儿子；连向它的是重边，其余轻边
- `1:11` 把重边连起来，树就被分成了若干条“重链”：每条重链从某个点（链顶）一直沿重儿子走到叶子。
  - 板书：重链：沿重边连成的链；每个点恰好属于一条重链
- `1:22` 这棵树被分成 7 条重链（同色的点在同一条链上，单独一个点也算一条链）。

## 走一条轻边，子树至少翻倍

- `1:35` 关键引理：如果 (u, v) 是轻边（v 是 u 的轻儿子），那么 size(v) ≤ size(u) / 2。
  - 板书：引理：轻边 (u, v)：size(v) ≤ size(u) / 2
- `1:44` 证明：u 的重儿子 h 的子树不比 v 小，size(h) ≥ size(v)。而 size(u) ≥ 1 + size(v) + size(h) > 2 × size(v)。
  - 板书：size(u) ≥ 1 + size(v) + size(h) ≥ 1 + 2·size(v)
- `1:56` 所以从任意一个点往根走，每经过一条轻边，所在子树的大小至少翻一倍。子树大小不超过 n，最多翻倍 log₂ n 次。
  - 板书：到根的路径上轻边 ≤ log₂ n 条 → 经过的重链 ≤ log₂ n + 1 条
- `2:08` 例：从 6 走到根，子树大小依次是 1 → 3 → 14。经过的轻边（红色）有 2 条，每条都让大小至少翻倍。
- `2:19` 任意两点之间的路径 = 两段“到 LCA 的向上路径”，所以也只经过 O(log n) 条重链。

## 重儿子优先的 DFS 序

- `2:32` 还要让每条重链在数组里连续：做 DFS 时先走重儿子，再走轻儿子。
  - 板书：DFS 先走重儿子 → 每条重链在 DFS 序里连续
- `2:40` 从链顶出发，DFS 会沿着重儿子一路走到底，中间不会岔出去，所以同一条链的点在数组里挨在一起，而且链顶在最前面。
- `2:53` 同时它仍然是 DFS 序：每棵子树依旧是一段连续区间 [dfn[u], dfn[u] + size(u) − 1]。
  - 板书：子树仍是区间：[dfn[u], dfn[u] + size(u) − 1]
  - 板书：记录：fa、dep、size、重儿子、top（链顶）、dfn

## 反例：不按大小选

- `3:06` 如果重儿子不是按子树大小选，而是随便选一个（比如总选第一个儿子）呢？
- `3:15` 这棵“梳子”树：一条长长的主干，每个点还挂着一片叶子。如果每次都把叶子当成“重儿子”，主干上的边全是轻边。
- `3:28` 从最深的点往上走，每一步都换一条链，经过 O(n) 条链，复杂度就退化了。按 size 选重儿子，主干就是一条链。
  - 板书：随便选重儿子：链的条数可能是 O(n) ✗
- `3:40` “选最大的儿子”保证了每条轻边都通向“不到一半”的子树，这是 log 的来源。

- `4:20` (1) 右儿子都是轻儿子。叶子 15 到根：15→7→3→1，三步全是轻边，最多 3 条（= log₂ 16 − 1）。
