## 期望的线性性：不需要独立

- `0:23` 随机变量 X 的期望 E[X] = Σ 取值 × 概率。最重要的性质：E[X + Y] = E[X] + E[Y]，对任何 X、Y 都成立，不要求独立。
  - 板书：E[X + Y] = E[X] + E[Y]（任何时候都成立）
- `0:35` 例：X 是骰子点数，Y = 7 − X 和 X 完全相关，可 E[X + Y] = 7/2 + 7/2 = 7 照样成立。证明只用到求和可以拆开：Σ(x + y)p = Σxp + Σyp。
- `0:48` 这让我们可以把一个复杂的量拆成很多简单的量分别求期望，完全不用管它们之间的关系。

## 指示变量：把“个数”拆成很多个 0/1

- `1:04` 随机打乱 1～4，期望有多少个位置上的数没动（不动点）？直接算分布：0 个、1 个……每种有几个排列？很麻烦。
- `1:16` 拆开：令 Iᵢ = 1 表示“位置 i 没动”，否则为 0。不动点个数 X = I₁ + I₂ + … + Iₙ。
  - 板书：指示变量：E[Iᵢ] = P(事件 i 发生)
- `1:25` E[Iᵢ] = P(位置 i 没动) = 1/4。由线性性，E[X] = 4 × 1/4 = 1。不管 n 是多少，期望都是 1 个不动点。
  - 板书：随机排列的不动点个数：期望 = n · (1/n) = 1
- `1:35` 验算：4! = 24 个排列一共有 24 个不动点，平均恰好 1 个。注意各个 Iᵢ 之间并不独立，但线性性不在乎。

## 倒着推：从终点定义状态

- `1:51` 格子 0～6，从 0 出发，每次掷硬币：正面前进 1 格，反面前进 2 格，到达或越过 6 就停。期望掷几次？
- `2:02` 正着想：从 0 出发，第 k 步走到每个格子的概率……要追踪整个分布，而且“停下”的时刻各不相同，很难写。
- `2:14` 倒着想：设 E[i] = 从格子 i 出发、还要掷的期望次数。终点 E[i] = 0（i ≥ 6）；其他格子掷一次，再分两种情况各占一半。
  - 板书：E[i] = 1 + ½E[i + 1] + ½E[i + 2]；E[≥ n] = 0
- `2:27` E[4] = 1 + ½·E[5] + ½·E[6] = 1 + ½·1 + ½·0 = 3/2。从右往左，每一格只依赖右边已经算好的。
- `2:37` 答案 E[0] = 135/32 ≈ 4.22 次。
  - 板书：答案 E[0] = 135/32
- `2:41` 为什么倒推方便？“从 i 出发还要多少步”只和 i 有关，与怎么走到 i 无关；而起点只有一个，答案就是 E[起点]。正推则要先知道到达每个状态的概率。
  - 板书：倒推：状态 = “从这里出发的未来”，与来路无关

## 一般形式：DAG 上按逆拓扑序

- `3:02` 一般地：DAG 上从 s 出发，每到一个点就等概率选一条出边走，边上数字是长度。到达 t 的期望总长度是多少？
- `3:14` E[a] = ½(2 + E[c]) + ½(6 + E[t]) = ½·3 + ½·6 = 9/2。每个点等于“走一步的长度 + 下一个点的期望”的平均。
- `3:26` 按逆拓扑序（t, c, b, a, s）算下来，E[s] = 23/4。
  - 板书：E[u] = Σ p(u → v) · (w + E[v])，按逆拓扑序计算

## 手推 / 建模题

- `3:36` 先别急着看答案：按暂停，在纸上推一推。
- `4:01` (1) 指示变量：盒子 j 为空的概率是 (2/3)³ = 8/27，3 个盒子：期望 3 × 8/27 = 8/9 个。
  - 板书：(1) 3 · (2/3)³ = 8/9
- `4:11` (2) 倒推：E[4] = E[5] = E[6] = 0，E[3] = 1，E[2] = 1 + (E[3] + E[4] + E[5])/3 = 4/3，E[1] = 16/9，E[0] = 64/27。
- `4:23` 所以期望走 64/27 ≈ 2.37 步。
  - 板书：(2) E[0] = 64/27
