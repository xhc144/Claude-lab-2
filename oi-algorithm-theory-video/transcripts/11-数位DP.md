## 问题：windy 数

- `0:20` windy 数：没有前导零，并且相邻两位数字之差的绝对值至少是 2。比如 135、352 是，121、88 不是。
  - 板书：windy 数：相邻两位之差 ≥ 2（无前导零）
- `0:32` 询问 [L, R] 里有多少个，R 可以到 2×10⁹，逐个检查太慢。
  - 板书：先转化：答案 = count(R) − count(L − 1)
- `0:39` 第一步转化：只要会算 count(N) = [1, N] 里的个数，区间答案就是 count(R) − count(L−1)。下面以 N = 352 为例。

## 把 ≤ N 的数分成几大块

- `0:55` 从最高位开始，一位一位地决定。三位数里：第一位如果小于 3（取 1 或 2），后面两位就随便取，不可能超过 352。
  - 板书：某一位比 N 小了 → 后面所有位都自由
- `1:07` 第一位如果等于 3，就还“贴着上界”：第二位只能取 0~5。第二位小于 5 时，最后一位随便；等于 5 时，最后一位只能取 0~2。
  - 板书：一直和 N 相等 → “贴着上界”，下一位受限
- `1:21` 每一块都是“固定的前缀 + 自由的后缀”。前缀本身要满足 windy 条件（比如 32x、33x、34x 的前缀已经不合法，整块是 0）。
  - 板书：≤ N 的三位数 = 若干个“固定前缀 + 自由后缀”的块
- `1:34` 块的个数很少：每一位最多 10 块，所以一共 O(位数 × 10) 块。问题变成：每一块里有多少个 windy 数？

## 自由的后缀：可以记忆化

- `1:50` 一个自由块里的个数，只取决于两件事：后面还有几位自由（rem），以及前缀的最后一位 d（下一位要和它差 ≥ 2）。
  - 板书：g[rem][d]：前一位是 d，后面 rem 位随便填，有多少种填法
  - 板书：g[0][d] = 1；g[rem][d] = Σ_{|e−d|≥2} g[rem−1][e]
- `2:02` 例：g[1][5]：前一位是 5，后一位只能取 0、1、2、3、7、8、9，共 7 种。
- `2:11` 块 1xx 的个数是 g[2][1]，2xx 是 g[2][2]，30x 是 g[1][0]……不同的块只要 (rem, d) 相同，就共用同一个值。
- `2:23` 而“贴着上界”的状态每一位只有一个（前缀和 N 完全相同），它不需要记忆化，也不能和自由的状态混在一起——它的下一位是受限的。
  - 板书：贴着上界的状态每位只有一个，单独处理；自由状态记忆化
- `2:38` 这就是数位 DP 的状态：(位置, 前一位, 是否贴着上界)。“是否贴着上界”决定下一位能取到几。
  - 板书：状态：(pos, 前一位, 是否贴上界)

## 前导零

- `2:51` 位数比 N 少的数怎么办？常见做法是补前导零：把 52 看成 052，统一成三位。
- `3:00` 但对 windy 数这样做会出错：13 是 windy 数，写成 013 后，0 和 1 只差 1，会被错误地排除。
  - 板书：补前导零后，0 不能参与“相邻差 ≥ 2”的判断
- `3:10` 所以要再加一个标记：数字是否已经“开始”。没开始时填 0 表示继续不开始，不受任何限制；第一个非零数字才算开始。
  - 板书：加标记 started：前导零不受限制
- `3:23` 对 N = 352：一位和两位的 windy 数一共 73 个，三位的各块加起来 119 个，count(352) = 192。暴力枚举验证也是 192。
  - 板书：count(352) = 73 + 119 = 192
- `3:36` 复杂度：位数 × 10 种前一位 × 2 × 2 个标记 × 10 种下一位，R = 2×10⁹ 时只有几千次运算。

## 手推 / 建模题

- `3:49` 先别急着看答案：按暂停，在纸上推一推。
- `4:15` (1) 下一位能不能填 2，取决于前一位是不是 6；4 是否出现，在填的时候直接禁止。所以只需记“前一位是不是 6”，再加上“是否贴上界”。
  - 板书：(1) 状态：(pos, 前一位是否为 6, 是否贴上界)
- `4:30` (2) 不需要。前导零 0 既不是 4，也不是 6，不会误伤任何数：62 写成 062 仍然含 62，该排除的照样排除。
  - 板书：(2) 前导零不影响判断 → 不需要
- `4:41` (3) 把 0~99 看成两位数 ab：a 有 9 种（除了 4），b 有 9 种，再去掉 62 这一个，共 80 个；去掉 00，再加上 100，答案 80。
  - 板书：(3) 9 × 9 − 1 − 1 + 1 = 80
- `4:54` 是否需要前导零标记，看的是“补上的 0 会不会改变判断”——这又是在问状态是否充分。
