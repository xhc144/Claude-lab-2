## 树状数组能做什么

- `0:21` 先回顾一下：树状数组的第 i 个格子 c[i] 管着一段 (i − lowbit(i), i]，lowbit(i) 是 i 的二进制里最低的那个 1。
  - 板书：c[i] 管 (i − lowbit(i), i]
- `0:33` 求前缀和 a[1] + … + a[7]：c[7] 管第 7 个，c[6] 管 5~6，c[4] 管 1~4，三块拼起来。每次去掉最低位的 1，最多 log n 块。
  - 板书：前缀和：沿 i → i − lowbit(i) 拼起来，O(log n)
- `0:46` 单点加 a[3] += x：所有管着第 3 个的格子都要改，c[3]、c[4]、c[8]，沿 i → i + lowbit(i) 往上走，也是 log n 个。
  - 板书：单点加：沿 i → i + lowbit(i) 修改，O(log n)
- `0:58` 它天生只会这两件事：单点修改、前缀求和。本集要做的，是通过换一个“维护对象”，让它支持区间操作。
  - 板书：基本能力：单点改 + 前缀和

## 区间加、单点查：差分

- `1:15` 操作变成：给 a[l..r] 每个数加 x，然后查询某个 a[p]。
  - 板书：问题一：区间加，单点查
- `1:22` 维护差分数组 d[i] = a[i] − a[i−1]。那么 a[p] 就是 d 的前缀和：a[p] = d[1] + d[2] + … + d[p]。
  - 板书：d[i] = a[i] − a[i−1]，a[p] = Σ_{k≤p} d[k]
- `1:32` 给 a[3..6] 加 2：区间内部相邻两数的差不变，只有左端 d[3] 多了 2，右端外面 d[7] 少了 2。
  - 板书：a[l..r] += x ⇔ d[l] += x，d[r+1] −= x
- `1:42` 所以区间加变成了 d 上的两次单点加，单点查询变成了 d 的前缀和——正好是树状数组会做的事。对 d 建树状数组就行。
  - 板书：对 d 建树状数组：两次单点加 + 一次前缀和

## 区间加、区间和：两个树状数组

- `1:59` 再进一步：区间加，区间求和。区间和可以拆成两个前缀和相减，所以只要会求前缀和 a[1] + … + a[p]。
  - 板书：问题二：区间加，区间求和 → 只要会求 Σ_{i≤p} a[i]
- `2:10` 把每个 a[i] 展开成 d 的前缀和，看看 d[k] 一共被加了几次：
- `2:18` 以 p = 5 为例：第 i 行是 a[i] 用到的 d[1..i]。d[k] 出现在第 k 行到第 p 行，一共 p − k + 1 次。
  - 板书：Σ_{i≤p} a[i] = Σ_{k≤p} d[k] × (p − k + 1)
- `2:28` 把 (p − k + 1) 拆开：= (p + 1) × Σ d[k]  −  Σ k × d[k]。前一项里 p 和 k 分开了，后一项只和 k 有关。
  - 板书：= (p + 1) × Σ d[k]  −  Σ k·d[k]
- `2:38` 两项都是“前缀和”：一个树状数组维护 d[k]，另一个维护 k·d[k]。区间加时两个数组各改两个点，求和时各查一次前缀。
  - 板书：树状数组 1 存 d[k]，树状数组 2 存 k·d[k]
- `2:51` 核心手法：前缀和里有一个随 p 变化的系数 (p − k + 1)，把它拆成“只和 p 有关”乘“只和 k 有关”的项之和，每一项就都能用树状数组维护。
- `3:06` 核对 p = 7：Σ d[1..7] = 2，Σ k·d[k] = -17，(7+1) × 2 − -17 = 33；直接把 a[1..7] 加起来也是 33。

## 变式与边界

- `3:19` 变式：给 [l, r] 加一个等差数列 x, x+t, x+2t, …。一阶差分 d 上变成“d[l] 加 x、d[l+1..r] 都加 t、d[r+1] 减掉末项”——仍然是区间加。
  - 板书：加等差数列：一阶差分上是区间加 → 再差分一次（二阶差分）
- `3:34` 于是再差分一次（二阶差分 e），等差数列加就变成 e 上的几个单点修改。查询时系数变成二次式，再按同样的方法拆开。
- `3:47` 边界：树状数组靠“前缀和相减”得到区间信息，要求信息可以相减。区间最大值不能相减，区间赋值也不能写成差分上的少数几次单点修改。
  - 板书：局限：信息要可减（max 不行）；修改要能变成差分上的单点（赋值不行）
- `4:02` 这些情况交给线段树——下一集讲线段树结点里该存什么。

## 手推 / 建模题

- `4:13` 先别急着看答案：按暂停，在纸上推一推。
- `4:39` a 变成 0 0 1 2 3 4 0 0。差分 d：区间内部每两个相邻数差 1，左端多 1，右端外面掉回 0，差 −4。
- `4:49` 再差分一次得到 e：只有三个位置非零——e[3] = 1，e[7] = −5，e[8] = 4。
  - 板书：e[l] += 1，e[r+1] −= len + 1，e[r+2] += len
- `4:58` 一般地：e[l] 加 1，e[r+1] 减 (len + 1)，e[r+2] 加 len。查询 a[p] 是 e 的“二重前缀和”，系数 (p − k + 1)，又回到了两个树状数组。
