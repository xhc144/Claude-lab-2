# 当概率开始旋转（用概率论讲傅里叶）

一部约 10 分 45 秒的数学动画短片：**用概率论重新解释傅里叶变换、傅里叶级数，以及卷积定理、中心极限定理、泊松求和、热方程、韦达公式、不确定性原理**。
可以看作 [《概率分布图鉴》](../probability-distributions-video/) 的续篇：片中多次回到那个系列里的内容（矩母函数、高尔顿板、二项与泊松、中心极限定理、柯西分布与灯塔）。

成片：[`当概率开始旋转.mp4`](当概率开始旋转.mp4)（1920×1080，30fps，H.264 + AAC）。

- **没有配音**。讲解写在画面下方的说明文字里，公式直接画在画面上；声音只有音效和环境铺底。
- 画面、公式、音效全部由 Python 程序生成，没有用任何素材文件。

## 一条主线

整部片子只用一个画面讲到底：

> 把随机变量 $X$ 的每个样本 $x$ 送到单位圆上角度为 $tx$ 的位置，再求这些点的**重心**。
> 这个重心就是特征函数 $\varphi(t)=\mathbb{E}[e^{itX}]$，也就是密度的傅里叶变换。

之后每一章都是“这个重心”的一条性质：

| 时间 | 章 | 傅里叶分析 | 概率论的解释 |
|---|---|---|---|
| 0:00 | 片头 | | 一把随机的点落在直线上，直线卷成圆、旋转起来，重心画出一条曲线 |
| 0:30 | 01 绕圈的重心 | 傅里叶变换、反演公式 | 特征函数是绕圈之后的重心；分布越窄，重心塌得越慢；矩母函数 $\mathbb{E}[e^{sX}]$ 把 $s$ 换成 $it$，增长变旋转，所以特征函数总存在；知道所有频率的重心就能还原密度 |
| 2:23 | 02 独立：加法变成乘法 | 卷积定理 | $X+Y$ 的密度是卷积；在圆上角度相加 = 旋转相乘，独立让“乘积的平均 = 平均的乘积”，所以 $\varphi_{X+Y}=\varphi_X\varphi_Y$；二项分布的 $n$ 次方取极限得到泊松分布 |
| 3:38 | 03 钟形曲线是不动点 | 高斯是自己的傅里叶变换 | 小频率下重心只往里缩 $t^2/2$，$n$ 次方把 $(1-t^2/2n)^n$ 推向 $e^{-t^2/2}$：中心极限定理；柯西分布的 $e^{-\lvert t\rvert}$ 有尖角，样本平均永远不收敛 |
| 4:59 | 04 圆上的随机：傅里叶级数 | 傅里叶级数、泊松求和公式 | 圆上的随机角度只能按整数圈数去绕（$\theta$ 和 $\theta+2\pi$ 是同一个点），频率因此变成离散的 $k$；$c_k=\mathbb{E}[e^{ik\Theta}]$ 是绕 $k$ 圈的重心；把直线缠到圆上，系数就是 $\varphi_X(k)$ |
| 6:32 | 05 热，就是随机游走 | 热方程（傅里叶 1822 年的原始问题） | 热是无数个独立做布朗运动的粒子；起点与路径独立，绕 $k$ 圈的重心每次乘上 $e^{-k^2s/2}$，高频先消失 |
| 7:43 | 06 抛硬币，抛出 π | 韦达公式、$\frac{\sin t}{t}=\prod\cos\frac{t}{2^k}$ | $[-1,1]$ 上的均匀分布就是二进制展开（步长减半的高尔顿板），每一位是一枚独立硬币；一枚 $\pm a$ 硬币的重心是 $\cos(ta)$，相乘再代入 $t=\pi/2$ |
| 8:54 | 07 两边不能同时尖 | 帕塞瓦尔恒等式、不确定性原理 | $\lvert f\rvert^2$ 和 $\lvert\hat f\rvert^2$ 都是概率密度（总概率守恒），两个标准差之积 $\ge 1/2$，只有高斯取等号；盒子的频谱方差无穷大 |
| 10:01 | 尾声 | | 十条对照；“傅里叶分析问的是：把一个随机的东西绕成圆，在每一种转速下，它的重心在哪里” |

画面里的数都是真算出来的：重心用分位数取的几千个样本求平均（和理论特征函数几乎重合），
中心极限定理一章是二项混合正态的精确密度，不确定性一章的 $\sigma_x\sigma_\xi$ 由 FFT 数值计算（高斯 0.500、$e^{-|x|}$ 0.707、双峰 1.82），π 的近似值是韦达乘积的前 $K$ 项。

## 声音

没有配音，`audio.py` 用 numpy 合成全部声音：

- **铺底**：每章一组和弦的慢速铺垫（Dm → B♭ → F → C → Gm → A → B♭ → Dm，尾声落在 D 大调），章与章之间交叉淡化。
- **“听得见的频率”**：画面里频率 $t$ 在变的时候，有一个音高跟着 $t$ 升高、音量跟着 $\lvert\varphi(t)\rvert$ 变小的持续音；重心塌向圆心时，声音也跟着消失。
- **音效**：章节开头的低频冲击、呼啸、公式出现时的钟声、说明文字出现时的轻响、样本落下的雨滴声、转盘指针的滴答、柯西平均乱跳时的故障声、铁环加热的噼啪声、扩散时的嘶嘶声、每多抛一枚硬币的一声“叮”……都按画面事件的时间表放置，再统一过一个合成的混响。
- 最后用 ffmpeg 的 `loudnorm` 把响度标准化到 −16 LUFS。

## 怎么重新生成

```bash
pip install skia-python numpy scipy matplotlib requests pillow
# skia-python 需要 libEGL：Debian/Ubuntu 上 apt-get install libegl1
python make.py                    # 字体 → 音轨 → 并行渲染 → 合成 → 压缩，约 30 分钟（4 核）
python make.py --stills 40,95.5   # 只渲染几个时刻的静帧到 build/stills/，调画面用
python make.py --audio            # 只重新生成音轨 build/audio.wav
```

不需要 LaTeX：公式由 matplotlib 的 mathtext（Computer Modern 字形）排版成轮廓，再转成 skia 的矢量路径，所以公式也能发光、能从左到右“写”出来。
字体（思源宋体、思源黑体、Orbitron、JetBrains Mono）第一次运行时从 Google Fonts 下载到 `build/fonts/`。
原画质成片在 `build/full.mp4`；仓库里放的是 `make.py` 最后一步压缩后的版本。

## 文件

| 文件 | 作用 |
|---|---|
| `make.py` | 一键生成：音轨、按帧段并行渲染、拼接、混音、压缩 |
| `timeline.py` / `scene.py` | 把各章场景排成时间线；每个场景带着自己的说明文字、音效提示和“频率的声音” |
| `s0_open.py` … `s8_finale.py` | 片头、七章、尾声，各一个文件；每个文件开头写着这一章讲什么 |
| `dist.py` | 片中用到的分布：混合正态、圆上的 von Mises 混合、伽马标准化，以及它们的特征函数和傅里叶系数 |
| `gfx.py` | 画图工具：缓动、配色、文字与公式、坐标系、粒子、背景 |
| `render.py` | 合成一帧：背景 → 场景 → 辉光 → 暗角 → 故障效果 → 说明文字；原始像素经管道交给 ffmpeg |
| `audio.py` | 全部声音的合成与混音 |
| `fonts.py` | 下载字体 |

每一帧只由时间决定（随机数都用固定种子），所以可以把整段切成几块并行渲染，任何一帧都能单独重画。
