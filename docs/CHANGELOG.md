# 更新记录

## 0.2.3

- **修复：自动更新下载成功却装不上**。从开始菜单或桌面快捷方式启动时，Folio 的当前目录就是程序目录，替换脚本继承了它，而 Windows 不允许给正被当作当前目录的文件夹改名，于是每次都悄悄退回旧版本。现在替换脚本和启动它的程序都切到临时目录；快捷方式的「起始位置」改成「文档」文件夹
- 自动更新失败时不再悄无声息：原因写进 `%TEMP%\folio-update-时间.log`，下次启动时提示「更新没有装上」，并给出手动下载的地址
- **注意**：替换是由旧版本执行的，所以从 0.2.2 及更早版本升级到 0.2.3 仍然需要手动下载安装一次；之后的自动更新就正常了
- **Windows 11 右键菜单**：「用 Folio 压缩」「用 Folio 合并」「用 Folio 转为 PDF」可以直接出现在第一层右键菜单里，不用再点「显示更多选项」；多选文件时一次全部交给同一个窗口。需要受信任的签名证书，证书不受信任时自动使用原来的菜单（见 README「Windows 11 右键菜单」）
- **设置窗口重新设计**：左边导航带图标，右边每一组选项是一张卡片，开关改成 Windows 11 风格的开关按钮，说明文字更清楚
- 标签上的关闭按钮（×）不再贴着标签右边缘，悬停底色和叉号都在正中间；提示文字改成中文「关闭标签」
- Windows 上菜单底部不再多出一条黑线（系统给弹出窗口加的直角阴影），菜单和提示框是真正的圆角
- Windows 上的界面字体改用微软雅黑 UI 并按像素对齐，中文不再偏下、发虚；分段选择（例如「跟随系统 / 浅色 / 深色」）更清楚
- 手动安装时会清理上次没装上的自动更新残留

## 0.2.2

- **右键菜单**：在桌面或资源管理器里右键 PDF，可以直接「用 Folio 压缩」「用 Folio 合并」；右键图片可以「用 Folio 转为 PDF」，不用先打开软件。一次选中多个文件再右键，它们会按文件名顺序放进同一个窗口。Windows 11 上在「显示更多选项」里（或按住 Shift 再右键）。不需要时可以在「设置 → 常规」里关掉
- **工具窗口不再挡住主窗口**：压缩、合并、拆分、图片转 PDF 现在是独立窗口，有自己的任务栏按钮，可以最小化；打开着工具窗口时，主窗口照样可以移动、最小化、继续阅读。文件拖到工具窗口的任何地方都能加进去
- **打开 PDF 时窗口会弹到最前面**：Folio 已经开着时双击 PDF，窗口会自动恢复（包括最小化的情况）并切到前台，不再只是任务栏闪一下
- **更新入口更好找**：主页底部显示当前版本和自动更新状态，可以直接「检查更新」；右上角的菜单在主页和阅读页都能看到；发现新版本时右上角会一直显示「新版本」按钮，点一下就能更新
- **界面细节**：标签栏改成和浏览器一样的样式，选中的标签和下面的工具栏连在一起；主页按钮、标签、加号、关闭按钮的大小和对齐都重新调整过；Windows 11 上标题栏颜色跟随界面（深色主题时标题栏也是深色）；窗口较窄时工具栏会收起次要按钮，不再挤在一起
- 同时打开多个文件时（例如一次双击好几个 PDF）只会有一个 Folio 窗口

## 0.2.1

- **Windows 安装程序**：新增 `Folio-Setup` 安装包，双击安装，自动创建开始菜单和桌面快捷方式，可以在系统设置里卸载；不需要管理员权限，安装后照常自动更新
- 可以把 Folio 加进 PDF 文件的“打开方式”

## 0.2.0

- **AI 中台**：在一个地方统一管理各家 AI 服务的地址和 Key（通义千问、DeepSeek、Kimi、智谱、硅基流动、OpenAI，以及本机的 Ollama、LM Studio 和任意 OpenAI 兼容服务），朗读、文字识别、AI 校对都从这里选用
- **文字识别（OCR）**：扫描件识别后可以搜索、选择、复制和朗读。可用系统自带识别（Windows OCR、macOS 文字识别、Tesseract），也可以用 AI 视觉模型（千问 OCR、本地 qwen3-vl 等）；还能用 DeepSeek 等文字模型校对识别结果
- 点读扫描页时会提示先识别文字，识别完自动开始朗读
- 朗读支持 OpenAI 兼容的语音接口（OpenAI、本地语音服务）
- **自动更新**：启动时检查新版本，下载后校验 SHA-256 和数字签名，关闭后自动替换并重新打开
- 打包流程支持 Windows 和 macOS 代码签名、macOS 公证
