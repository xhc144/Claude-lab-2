## 问题：一组差分不等式

- `0:21` 有 4 个未知数 x₁…x₄，以及下面 5 条约束，每条都是“两个未知数之差不超过某个数”。
  - 板书：约束：xᵥ − xᵤ ≤ w；求一组解或判定无解
- `0:31` 比如“x₃ − x₂ ≤ −1”就是“x₃ 至少比 x₂ 小 1”。排日程、安排时刻表时经常遇到这种约束。
- `0:41` 看一眼最短路：算完最短路后，对每条边 u → v（边权 w）一定有 d[v] ≤ d[u] + w，否则还能再松弛。
  - 板书：最短路的三角形不等式：d[v] ≤ d[u] + w(u, v)
- `0:52` 把它移项：d[v] − d[u] ≤ w。和约束 xᵥ − xᵤ ≤ w 一模一样！
  - 板书：xᵥ − xᵤ ≤ w ⇔ 建边 u → v，边权 w

## 建图：每条约束一条边

- `1:03` 每条约束 xᵥ − xᵤ ≤ w 建一条边 u → v，权值 w。注意方向：被减的 xᵤ 是起点。
- `1:12` 再加一个超级源点 0，向每个变量连一条权值 0 的边。这相当于多加约束 xᵢ − x₀ ≤ 0，保证从 0 出发能到达每个点。
  - 板书：超级源点 0 → 每个变量，权 0（相当于 xᵢ ≤ x₀）
- `1:24` 从 0 跑最短路（有负权，用 Bellman-Ford），令 xᵢ = d[i]。由三角形不等式，所有约束自动满足。
  - 板书：令 xᵢ = d[i] → 所有约束成立

## 跑一遍 Bellman-Ford

- `1:40` Bellman-Ford：每一轮把所有边都松弛一遍。右边表格记录每轮结束时的 d。
- `1:49` 第一轮：变量都是 ∞，约束边松弛不动，只有源点的边把它们都设成 0。
- `1:57` 第二轮：负权的约束边开始起作用，x₃ 被压到 −1，x₁ 被压到 −2。再来一轮，什么都没变，结束。
- `2:08` 稳定后得到 x = (-2, 0, -1, 0)。逐条代入检查：x2 − x1 = 2 ≤ 3；x3 − x2 = -1 ≤ -1；x3 − x1 = 1 ≤ 1……全部成立。
- `2:20` 这组解还有个性质：在“xᵢ ≤ 0”的前提下，每个 xᵢ 都取到了能取的最大值（最短路给出的是“最紧的上界”）。整体加同一个常数仍然是解。

## 负环 ⇔ 无解

- `2:38` 如果约束互相矛盾呢？例如 x₂ − x₁ ≤ 1，x₃ − x₂ ≤ −2，x₁ − x₃ ≤ 0。
- `2:45` 建出图来是一个环，边权之和 1 + (−2) + 0 = −1 < 0，是负环。
- `2:52` 把环上三条约束加起来：左边 (x₂ − x₁) + (x₃ − x₂) + (x₁ − x₃) = 0，右边是 −1，得到 0 ≤ −1，矛盾。所以有负环一定无解。
  - 板书：负环：把环上的约束相加得 0 ≤ 负数 → 无解
- `3:05` 反过来，没有负环时最短路存在，按上面的方法就能构造出解。所以：有解 ⇔ 图中没有负环。
  - 板书：有解 ⇔ 没有负环（Bellman-Ford 第 n 轮还能松弛就是负环）

## 各种不等式的转化

- `3:19` 实际题目里的约束不一定是“≤”的标准形式，要先转化：
  - 板书：xᵥ − xᵤ ≥ w ⇔ xᵤ − xᵥ ≤ −w（边 v → u，权 −w）
  - 板书：xᵥ = xᵤ ⇔ xᵥ − xᵤ ≤ 0 且 xᵤ − xᵥ ≤ 0
  - 板书：整数且 xᵥ − xᵤ < w ⇔ xᵥ − xᵤ ≤ w − 1
  - 板书：xᵢ ≤ c ⇔ xᵢ − x₀ ≤ c（借助源点 x₀ = 0）
- `3:26` “≥” 就把两边同乘 −1；等式拆成两个不等式；整数的严格不等式减 1；单个变量的上下界借助一个固定为 0 的源点。
- `3:39` 如果要求某个量的最小值，常把所有约束改写成“≥”的形式求最长路，原理完全对称。
  - 板书：求最小值：写成 ≥，跑最长路

## 手推 / 建模题

- `3:53` 先别急着看答案：按暂停，在纸上推一推。
- `4:18` (1) [a, b] 里选的个数是 S_b − S_{a−1}，所以约束是 S_b − S_{a−1} ≥ c。
  - 板书：(1) S_b − S_{a−1} ≥ c
- `4:26` (2) 每个数要么选要么不选：0 ≤ Sᵢ − Sᵢ₋₁ ≤ 1。这两条很容易漏掉，没有它们，解可能出现“选了负数个”。
  - 板书：(2) 隐含：0 ≤ Sᵢ − Sᵢ₋₁ ≤ 1
- `4:38` 所有约束都是差分约束。要 S₁₀ 最小，就把它们写成“≥”的形式，从 S₋₁ 出发求到 S₁₀ 的最长路。
  - 板书：求 S₁₀ 的最小值 = 最长路
