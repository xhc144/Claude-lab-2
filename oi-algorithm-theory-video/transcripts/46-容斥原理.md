## 三个集合：加、减、再加

- `0:24` A、B、C 分别是 1～30 里 2、3、5 的倍数。图里分成 7 块，每块写的是“这块里的数被算了几次”。
  - 板书：|A ∪ B ∪ C| = Σ|A| − Σ|A ∩ B| + |A ∩ B ∩ C|
- `0:35` 先加上 |A| + |B| + |C| = 15 + 10 + 6 = 31。两块重叠的地方被算了 2 次，中间算了 3 次。
- `0:46` 减去两两的交：|A∩B| + |A∩C| + |B∩C| = 5 + 3 + 2。重叠处变回 1 次，可中间被减了 3 次，变成 0 次。
- `0:58` 再加回三者的交 |A∩B∩C| = 1：每一块都恰好是 1 次。
- `1:04` 所以 |A ∪ B ∪ C| = 31 − 10 + 1 = 22。
  - 板书：1～30 中被 2、3、5 之一整除的数：22 个

## 为什么每个元素恰好算一次

- `1:13` 一般形式：对所有非空的条件子集 T 求交集的大小，按 |T| 的奇偶加或减。
  - 板书：|A₁ ∪ … ∪ Aₙ| = Σ (−1)^{|T|+1} |∩ T|（T 取遍非空子集）
- `1:21` 看一个恰好属于 t 个集合的元素（t ≥ 1）。它出现在“从这 t 个里选出 j 个”的交集里，被计了 C(t, 1) − C(t, 2) + C(t, 3) − … 次。
- `1:35` 由二项式定理，1 − C(t,1) + C(t,2) − … = (1 − 1)ᵗ = 0，所以 C(t,1) − C(t,2) + … = 1。每个元素恰好算一次，不属于任何集合的元素算 0 次。
  - 板书：恰属于 t 个集合的元素被计 1 − (1 − 1)ᵗ = 1 次

## 错排：没有人拿到自己的帽子

- `1:53` 4 个人各有一顶帽子，打乱后重新分，没有人拿到自己的帽子，有几种分法？
- `2:02` 设 Aᵢ 为“第 i 个人拿到自己的帽子”的排列。至少固定某 k 个人：剩下的随便排，(n − k)! 种；选哪 k 个人：C(n, k) 种。
  - 板书：|Aᵢ₁ ∩ … ∩ Aᵢₖ| = (n − k)!
- `2:15` 一个都不固定 = 全部 − 至少一个被固定：D4 = Σ (−1)ᵏ C(n, k)(n − k)! = 9。
  - 板书：Dₙ = Σ (−1)ᵏ C(n, k)(n − k)! = n! Σ (−1)ᵏ/k!
- `2:23` n 很大时 Dₙ/n! → 1/e ≈ 0.368：随便打乱，大约三分之一的概率谁都没拿到自己的帽子。

## 有上界的不定方程

- `2:37` x₁ + x₂ + x₃ = 10，0 ≤ xᵢ ≤ 4。插板法只能处理下界；上界用容斥：Aᵢ = “xᵢ ≥ 5”（违反上界）。
  - 板书：上界：Aᵢ = “xᵢ 超过上界”，容斥后每个都用插板
- `2:47` 选定 j 个变量先各发 5，剩下的和插板。注意符号交替。
- `2:54` 答案 6：(2, 4, 4)、(3, 3, 4) 各有 3 种排列，正好 6 组。
  - 板书：例：x₁ + x₂ + x₃ = 10，xᵢ ≤ 4：6 组

## “至少”与“恰好”

- `3:05` 容斥里算的 |∩T| 是“至少满足 T 里这些条件”。设 f(k) = 所有大小为 k 的 T 的 |∩T| 之和，g(k) = 恰好满足 k 个条件的元素个数。
  - 板书：f(k) = Σ_{|T| = k} |∩ T|（至少）；g(k) = 恰好 k 个
- `3:18` 恰好满足 j 个条件的元素，在 f(k) 里被数了 C(j, k) 次（从它满足的 j 个里选 k 个）。所以 f(k) = Σⱼ C(j, k) g(j)。
  - 板书：f(k) = Σ_{j ≥ k} C(j, k) g(j)  ⇔  g(k) = Σ_{j ≥ k} (−1)^{j−k} C(j, k) f(j)
- `3:30` 以 4 个人的帽子为例：f(k) = C(4, k)(n − k)!，g(k) 是恰好 k 人拿到自己帽子的排列数。反过来用二项式反演，就能从 f 求出 g；g(0) 就是错排数 9。
