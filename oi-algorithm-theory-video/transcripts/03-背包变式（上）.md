## 一维数组里的“新”与“旧”

- `0:22` 先回到二维的写法。f[i][j]：只考虑前 i 个物品、容量为 j 时的最大价值。下面两个物品：体积 2 价值 3，体积 3 价值 4。
  - 板书：f[i][j]：前 i 个物品，容量 j，最大价值
- `0:35` 0/1 背包：f[i][j] = max(f[i−1][j], f[i−1][j−w] + v)。两个来源都在上一行——第 i 个物品最多用一次。
  - 板书：0/1：f[i][j] ← f[i−1][j]，f[i−1][j−w] + v（都在上一行）
- `0:47` 完全背包只改一处：f[i][j] = max(f[i−1][j], f[i][j−w] + v)。第二个来源在同一行，意思是“已经可能用过第 i 个，还可以再用一个”。
  - 板书：完全：f[i][j−w] + v（在同一行）→ 第 i 个可以再用
- `1:01` 压成一维数组时，f[j] 里同时住着两行：已经更新过的位置是这一行（新），还没更新的位置是上一行（旧）。
  - 板书：一维：已更新的位置 = 新行，未更新的 = 旧行
- `1:14` 倒序循环（j 从大到小）：算 f[j] 时，f[j−w] 在左边，还没更新，仍是上一行的值——这就是 0/1 背包。
- `1:25` 每次读到的 f[j−3] 都是灰色的旧值：物品 2 只被用了一次。结果和二维表的第 2 行完全一样。
- `1:35` 如果改成正序循环，算 f[j] 时 f[j−w] 已经是新值——它可能已经含有物品 2，再加一次就是“用两次”。这正是完全背包要的效果。
  - 板书：倒序 → f[j−w] 是旧的 → 0/1；正序 → 新的 → 完全
- `1:49` 所以循环方向不是需要背的规则，而是在选择：f[j−w] 读的是上一行，还是这一行。

## 初值决定含义

- `2:03` 同样的转移，问“容量不超过 j”和“恰好装满 j”，答案不同。区别只在初值。
- `2:11` 初值就是“一个物品都不选”时的答案。什么都不选，体积恰好是 j 只在 j = 0 时可能，其他容量“做不到”，记为 −∞。
  - 板书：初值 = 一个物品都不选时的答案
  - 板书：恰好：f[0] = 0，f[j>0] = −∞（做不到）
- `2:24` 而“不超过 j”时，什么都不选对任何容量都合法，价值 0。
  - 板书：不超过：f[j] = 0
- `2:31` 把两个物品依次加进去：
- `2:35` “恰好”只在能凑出的体积 0、2、3、5 上有值；“不超过”的 f[j] 正好是“恰好”表里 f[0..j] 的最大值。
  - 板书：不超过的 f[j] = max(恰好的 f[0..j])
- `2:46` 一句话：状态的定义写清楚，初值就是这个定义在“零个物品”时的取值，不需要记。

## 多重背包：二进制拆分

- `3:00` 多重背包：第 i 种物品有 c 个。最直接的做法是把它拆成 c 个一模一样的 0/1 物品，复杂度 O(V · Σc)。
  - 板书：朴素：拆成 c 个 0/1 物品，O(V·Σc)
- `3:11` 其实我们只关心“这种物品最终用了几个”，用 0 个到 c 个都要能表示，而且不能超过 c 个。
  - 板书：要求：能凑出 0..c 中的每个数量，且不能超过 c
- `3:21` 以 c = 13 为例：拆成 1、2、4，再加上剩下的 6。四个“包”各当成一个 0/1 物品，体积和价值都乘上份数。
  - 板书：c = 13 → 1、2、4、6（四个 0/1 物品）
- `3:33` 为什么每个数量都能凑出来？前三个包 1、2、4 用二进制可以凑出 0 到 7 的任何数。
- `3:42` 大于 7 的数量 m（8 到 13），先拿走最后的 6，剩下 m − 6 在 2 到 7 之间，又能用 1、2、4 凑出来。
- `3:52` 而所有包加起来正好是 13，选得再多也不会超过 c。“不少”和“不多”都成立，所以拆分前后可选的数量集合完全相同。
  - 板书：不少：0..c 都能凑出；不多：总和恰为 c
- `4:05` 为什么最后一份不能也是 8？1+2+4+8 = 15，会凑出 14、15 个，比实际拥有的多——这就是“不多”被破坏了。
- `4:17` 一般地：取 1, 2, 4, …, 2^(k−1)，只要总和不超过 c；最后一份是剩下的 r，r 比 2^k 小。每种物品只拆成 O(log c) 份。
  - 板书：复杂度 O(V · Σ log c)（单调队列还能做到 O(nV)，见第 12 集）

## 计数：组合还是排列

- `4:33` 背包也常用来计数。面值 1 和 2 的硬币各有无限个，凑出 4 有几种方法？
  - 板书：硬币 {1, 2}，凑出 4
- `4:41` 如果不计顺序（1+1+2 和 2+1+1 算一种），答案是 3：{1,1,1,1}、{1,1,2}、{2,2}。如果计顺序，答案是 5。
  - 板书：不计顺序：3 种；计顺序：5 种
- `4:53` 写法一：外层枚举硬币，内层枚举容量。先把面值 1 全部处理完，再处理面值 2。
- `5:02` 这样每种组合只会以“先放所有 1、再放所有 2”这一种顺序被数到，所以数的是组合：3。
  - 板书：外层物品：硬币按固定顺序加入 → 数组合
- `5:13` 写法二：外层枚举容量 j，内层枚举“最后一枚是哪种硬币”：g[j] = g[j−1] + g[j−2]。
- `5:22` 按“最后一枚”分类，1+1+2 和 1+2+1 最后一枚不同，会分别被数到，所以数的是排列：5。
  - 板书：外层容量、按最后一枚分类 → 数排列
- `5:32` 两种写法都对，只是数的东西不同。读题时先想清楚：顺序不同算不算不同的方案。

## 反例：方向写反

- `5:46` 反过来，如果 0/1 背包用了正序循环，会发生什么？一个物品：体积 2、价值 3，容量 4。
- `5:56` f[4] = f[2] + 3 = 6：f[2] 已经是“用过这个物品”的新值，于是这个物品被用了两次。只有一个物品，正确答案是 3。
  - 板书：0/1 背包正序：f[4] = 6（物品用了两次）✗

## 手推 / 建模题

- `6:12` 先别急着看答案：按暂停，在纸上推一推。
- `6:38` (1) 不计顺序：外层枚举硬币，内层容量正序（硬币无限个）。
- `6:45` 答案 f[10] = 10。可以核对：不用 5 有 6 种（2 的个数 0~5），用一个 5 有 3 种，用两个 5 有 1 种。
  - 板书：不计顺序：10
- `6:56` (2) 计顺序：外层容量，按最后一枚分类，g[j] = g[j−1] + g[j−2] + g[j−5]，g[0] = 1，得到 g[10] = 128。
  - 板书：计顺序：g[j] = g[j−1] + g[j−2] + g[j−5]，g[10] = 128
