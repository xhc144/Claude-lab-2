## 求值就是乘一个矩阵

- `0:28` 在 n 个单位根上求值：yⱼ = Σₖ aₖ ωʲᵏ。写成矩阵就是 y = V a，V 的第 j 行第 k 列是 ωʲᵏ。
  - 板书：DFT：y = V a，V[j][k] = ω^{jk}
- `0:37` n = 4 时 ω = i，矩阵里都是 i 的幂。逆变换就是求 V 的逆矩阵。
- `0:45` 神奇之处：V 的逆几乎就是它自己——把 ω 换成 ω⁻¹，再整体除以 n。
  - 板书：V⁻¹ = (1/n) · V(ω⁻¹)

## 为什么逆变换只是换成 ω⁻¹

- `0:56` 看 V(ω) 和 V(ω⁻¹) 相乘的第 (j, l) 个元素：Σₖ ωʲᵏ · ω⁻ᵏˡ = Σₖ (ω^{j−l})ᵏ。
  - 板书：Σₖ (ω^{j−l})ᵏ：j = l 时为 n，否则为 0
- `1:05` j = l 时每一项都是 1，和为 n。j ≠ l 时，这是 n 个均匀分布在单位圆上的向量（图里 n = 8），首尾相接回到原点，和为 0。
- `1:18` 严格地：这是公比 q = ω^{j−l} ≠ 1 的等比数列，和 = (qⁿ − 1)/(q − 1)，而 qⁿ = 1，所以为 0。
  - 板书：等比求和：(qⁿ − 1)/(q − 1) = 0（因为 qⁿ = 1）
- `1:27` 所以 V(ω) · V(ω⁻¹) = n · I。逆变换和正变换是同一个 FFT 程序，只是单位根换成 ω⁻¹，最后每个数除以 n。

## 完整的乘法：(1 + 2x)(3 + x)

- `1:44` 乘积是 2 次多项式，要 3 个点，补到 2 的幂 n = 4。两个多项式各做一次 FFT，逐点相乘，再做一次逆 FFT。
- `1:55` 结果 3 + 7x + 2x²，正是 (1 + 2x)(3 + x)。三次 FFT 加一次逐点乘：O(n log n)。
  - 板书：乘法：两次 FFT + 逐点乘 + 一次逆 FFT，O(n log n)
- `2:04` 实际计算用浮点数，cos、sin 有舍入误差。系数很大或项数很多时，误差可能让四舍五入出错。题目要取模时，能不能直接在模 p 的整数里做？
  - 板书：浮点 FFT：有精度误差

## 在模 p 下找“单位根”

- `2:23` FFT 用到单位根的三条性质：ωⁿ = 1；ω⁰…ωⁿ⁻¹ 互不相同；ω^{n/2} = −1（平方后减半）。模素数 p 时，能找到满足这些性质的整数吗？
  - 板书：需要：ωⁿ ≡ 1，前 n 个幂互不相同，ω^{n/2} ≡ −1
- `2:37` 例：p = 17，3 是它的原根（3 的幂能取遍 1～16）。取 ω = 3^{(p−1)/n}。n = 8 时 ω = 3² = 9。
- `2:47` 8 个幂互不相同，ω⁸ = 1，ω⁴ = 16 ≡ −1。三条性质都满足，FFT 的推导一字不改就能在模 17 下进行。这就是 NTT（数论变换）。
  - 板书：p = c·2ᵏ + 1，原根 g：ωₙ = g^{(p−1)/n}（例：p = 17，ω₈ = 9）
- `3:00` 为什么 ω^{n/2} ≡ −1？它的平方是 ωⁿ ≡ 1，又不等于 1（原根的性质），模素数时平方为 1 的只有 ±1。
- `3:11` 条件是 n 整除 p − 1。竞赛里最常用 p = 998244353 = 119 × 2²³ + 1，原根是 3：长度 2 的幂、不超过 2²³ 都可以。
  - 板书：998244353 = 119 · 2²³ + 1，原根 3

## NTT 的适用条件

- `3:26` NTT 全程整数运算、没有精度问题，但答案是模 p 的：题目本来就要求模 998244353 时最合适。
  - 板书：① 答案要求模 p（或真实系数小于 p）
- `3:37` 逆变换照样成立：用 ω⁻¹（模 p 的逆元），最后乘以 n 在模 p 下的逆元。
  - 板书：② 逆变换：ω⁻¹ 与 n⁻¹ 都用模 p 的逆元
- `3:45` 如果模数是任意的（比如 10⁹ + 7，它减 1 不含足够大的 2 的幂），可以用三个 NTT 模数分别算，再用中国剩余定理合并；或者把系数拆开用浮点 FFT。
  - 板书：③ 任意模数：三模数 NTT + CRT，或拆系数的 FFT

## 手推 / 建模题

- `4:05` 先别急着看答案：按暂停，在纸上推一推。
- `4:30` (1) ω₄ = 3^{16/4} = 3⁴ = 81 ≡ 13。13² = 169 ≡ 16 ≡ −1 ✓。
  - 板书：(1) ω₄ = 13
- `4:37` (2) 四个点依次是 1、13、16、4，代入 1 + 2x 取模：1 + 2·1 ≡ 3、1 + 2·13 ≡ 10、1 + 2·16 ≡ 16、1 + 2·4 ≡ 9。
  - 板书：(2) NTT = 3、10、16、9
- `4:48` (3) 4 × 13 = 52 = 3 × 17 + 1，所以 4⁻¹ ≡ 13。用 ω⁻¹ = 4 再做一次变换、每项乘 13，就回到 1, 2, 0, 0。
  - 板书：(3) 4⁻¹ ≡ 13；逆变换得回 1, 2, 0, 0
