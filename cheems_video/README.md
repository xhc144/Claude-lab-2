# Cheems规则怪谈：月光宠物旅馆

一部约 16.6 分钟的原创动画短片：剧本、角色、场景、动画、配乐、音效全部由本目录的代码生成，
配音使用阿里云百炼（千问语音合成 `qwen3-tts-flash`）。

## 故事梗概（含剧透）

胆小又贪吃的柴犬 Cheems 被主人寄养在「月光宠物旅馆」，夜里在饭碗底下发现了七条《夜间住客守则》：
看到两只橘猫要闭眼数到十、闻到肉骨头不要吃、哈士奇叫你名字不要答应、没带牵引绳的「主人」不是主人、
天亮前不要照镜子……

一夜之间，守则一条条应验，邻居一个个消失；老金爷爷又从通风口递来一张《真正的规则》，句句和守则相反。
层层反转：

1. 旅馆里没有鬼，只有**偷狗贼**——每条守则背后都有现实的解释（遥控玩具猫的夜视摄像头、下了药的骨头、
   夜里会变成镜子的窗户）。
2. 会学人说话的鹦鹉阿福是贼寄养进来的「卧底」；而能识破它的线索，早在白天就埋下了：二哈一直把 Cheems
   叫成「芝士」。
3. 递纸条的老金，是因为被主人抛弃、太想有个家，才被贼利用。
4. 店长说：店里从来没写过什么守则——写守则的橘猫管理员大橘，七年前就为了保护狗狗再也没有回来。
5. 片尾彩蛋：Cheems 在新家的家规下面写了一句「家规里有一条是假的m」。

## 角色

Cheems（柴犬）、大橘（橘猫管理员）、二哈（哈士奇）、小柯（柯基）、大壮（健身柴）、老金（金毛）、
阿福（鹦鹉）、主人、偷狗贼、王店长、遥控玩具猫，以及小天使 / 小恶魔 Cheems。

## 生成

依赖：Python 3.10+、ffmpeg、`pip install skia-python numpy scipy pillow`（Linux 还需要 `libegl1`）。

```bash
./fetch_fonts.sh                                   # 下载 OFL 字体到 fonts/
export DASHSCOPE_API_KEY=sk-...                    # 你的百炼 API Key（不要提交到仓库）
python make.py --work /tmp/cheems --out 成片.mp4 --jobs 4
```

`make.py` 依次：生成配音（按音色 + 文本缓存）→ 按配音实际时长排时间轴并混音 → 分段并行渲染 → 拼接 → 合成 AAC 音轨（响度归一到 -15 LUFS）。

## 文件

| 文件 | 内容 |
| --- | --- |
| `script.py` | 剧本：20 场、179 句台词，角色音色、语速、语音特效、音效提示 |
| `tts.py` | 调用百炼千问 TTS，结果缓存为 wav |
| `engine.py` | 时间轴：每一拍的起止时间、嘴型同步、表情状态；整片混音 |
| `audio.py` | 语音特效（鹦鹉模仿、通风口、隔墙、回忆）、原创配乐、音效、环境声 |
| `gfx.py` | skia 绘图基础：颜色、样条、渐变、文字、缓动 |
| `chars.py` / `humans.py` | 角色绘制（表情、眨眼、口型、尾巴、走路） |
| `sets.py` | 场景：旅馆外景、大堂、走廊、房间、美容室、面包车、新家 |
| `overlays.py` | 守则纸条、时间卡、字幕、片名、真相解说卡、片尾字幕、暗角颗粒 |
| `scenes.py` | 分镜和表演：每一场的镜头运动、走位、灯光 |
| `render.py` | 逐帧渲染并直接把像素送给 ffmpeg 编码 |
