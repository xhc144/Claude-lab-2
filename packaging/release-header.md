## 下载哪个文件？

| 文件 | 给谁用 | 怎么用 |
|---|---|---|
| **Folio-Setup-版本号.exe** | Windows 10 / 11 电脑（**推荐**） | 双击安装，一路“下一步”。装好后在开始菜单和桌面打开 Folio，以后在“设置 → 应用”里可以卸载。不需要管理员权限。 |
| Folio-windows.zip | Windows，不想安装的人 | 免安装版：右键“全部解压缩”，打开 `Folio` 文件夹，双击 `Folio.exe`。 |
| Folio-macos.zip | Apple 芯片（M1 / M2 / M3 / M4）的 Mac | 解压得到 `Folio.app`，拖进“应用程序”。第一次打开如果提示“无法验证开发者”，在 Folio 上右键 → 打开。 |
| latest.json | 不用管 | 程序自己用来检查新版本的文件。 |
| Source code | 不用管 | GitHub 自动附带的源代码。 |

已经装了 Folio 的话不用重新下载：程序启动时会提示有新版本，确认后自动更新。
