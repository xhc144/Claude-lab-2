## 要留下哪些点

- `0:30` 黄色是这次询问的关键点 6, 8, 11, 13。很多树形 DP 只关心关键点之间的“分叉”结构，中间一长串只有一个儿子的点可以缩掉。
  - 板书：虚树：只保留关键点和它们两两的 LCA，压缩其余的链
- `0:43` 需要保留的是关键点、它们两两的 LCA（分叉处），再加上根。可两两 LCA 有 O(k²) 对，要全部算吗？
- `0:55` 不用。把关键点按 DFS 序排好，只算相邻两个的 LCA 就够了：LCA(6, 8) = 2、LCA(8, 11) = 1、LCA(11, 13) = 3。
  - 板书：按 DFS 序排序后，相邻关键点的 LCA 就包含了所有两两 LCA
- `1:06` 为什么？任取 aᵢ、aⱼ（i < j，按 DFS 序）。它们的 LCA 是 aᵢ 到 aⱼ 之间相邻各对 LCA 里最浅的那个——因为 DFS 序在 aᵢ、aⱼ 之间的点都在 LCA(aᵢ, aⱼ) 的子树里。
- `1:23` 所以虚树最多 k 个关键点 + (k − 1) 个 LCA = 2k − 1 个点（不算额外加的根）。这里正好 7 个。
  - 板书：虚树至多 2k − 1 个点（+ 根）

## 用栈建树

- `1:36` 按 DFS 序依次加入关键点，用一个栈维护“虚树上从根到当前点的那条链”。栈底是根。
  - 板书：栈 = 虚树中从根到最近加入点的链
- `1:46` 加入 8：它和栈顶 6 的 LCA 是 2，不在栈里。说明 6 那一支已经结束了：连上 2 → 6，再把栈顶换成 2，最后压入 8。
- `1:58` 加入 11：LCA(11, 8) = 1。比 1 深的栈元素都要出栈，出栈时把它和下面一个连边：2 → 8，1 → 2。然后压入 11。
  - 板书：弹栈直到栈顶的深度 ≤ LCA；弹出时与下面的元素连边；必要时把 LCA 压进去
- `2:10` 加入 13：LCA(13, 11) = 3 不在栈里：连 3 → 11，栈顶换成 3，压入 13。
- `2:18` 所有关键点加入后，栈里剩下的链依次连边。橙色的边就是虚树：1 → 2、1 → 3、2 → 6、2 → 8、3 → 11、3 → 13。
- `2:29` 每个点进栈、出栈各一次，每次求一个 LCA：建树 O(k log n)。在虚树上做树形 DP，就只和 k 有关了。
  - 板书：建虚树 O(k log n)；所有询问合计 O(Σk · log n)

## 虚树上的 DP 要注意什么

- `2:45` 例：切断一些边让所有关键点和根不连通，最小代价是多少？在原树上是树形 DP，在虚树上同样做，只是虚树的一条边代表原树的一整条链。
  - 板书：虚树的一条边 = 原树的一条链：边上的信息要先汇总（如链上的最小边权）
- `3:00` 所以要预处理“链上的信息”：比如每个点到根路径上的最小边权，虚树边 u → v 的代价就是 v 到 u 那段链上的最小边权（用倍增求）。
- `3:14` 另一个细节：每次询问用完要把虚树清空，只清自己用过的点，不能 O(n) 清整棵树。
  - 板书：每次询问只清理用过的点
