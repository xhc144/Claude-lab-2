## border：既是前缀，又是后缀

- `0:27` 先补一个概念：字符串 s 的 border，是 s 的一个真前缀（不等于 s 本身），同时也是 s 的后缀。
  - 板书：border：既是真前缀又是后缀的串
- `0:37` 长度 3：前 3 个字符是 aba，后 3 个字符也是 aba，所以 aba 是一个 border。
- `0:45` 长度 1：前 1 个字符是 a，后 1 个字符也是 a，所以 a 是一个 border。
  - 板书：abacaba 的 border：aba、a（还有空串）
- `0:53` KMP 用到的是“最长 border”：把前 i 个字符的最长 border 长度记作 π[i]。π 就是 KMP 的失配数组（也叫 next）。
  - 板书：π[i] = s 的前 i 个字符的最长 border 长度

## border 的 border 还是 border

- `1:10` 一个关键事实：s 的全部 border，可以从最长的那个出发，一个套一个地全部找出来。
- `1:20` 设 t 是 s 的任意一个更短的 border。t 是 s 的前缀，也就是最长 border aba 的前缀；t 是 s 的后缀，也就是 aba 的后缀。
- `1:33` 所以 t 既是 aba 的前缀又是它的后缀——t 是“最长 border 的 border”。这里 t = a。
  - 板书：s 的 border = 最长 border b₁，以及 b₁ 的所有 border
- `1:42` 反过来，border 的 border 当然还是 s 的 border。于是：s 的全部 border 恰好是 π 沿着自己一路跳下去的那条链。
  - 板书：全部 border：π[n] → π[π[n]] → … → 0（失配链）
- `1:54` 例如 abacaba：π[7] = 3，π[3] = 1，π[1] = 0。链 7 → 3 → 1 → 0 正好给出全部 border：aba、a。

## 沿失配链计算 π

- `2:08` 对模式串 abacabab 从左到右算 π。π[1] = 0（单个字符没有真前缀）。
- `2:17` 算 π[i] 时，前 i 个字符的 border 去掉最后一个字符，就是前 i − 1 个字符的 border。所以只要在“前 i − 1 个字符的全部 border”里找。
  - 板书：前 i 个的 border = 前 i − 1 个的某个 border + 第 i 个字符
- `2:31` 候选从长到短就是失配链 j = π[i − 1], π[j], …；第一个满足“s[j + 1] = s[i]”的 j，给出 π[i] = j + 1。
  - 板书：j 从 π[i − 1] 起沿链跳，直到 s[j + 1] = s[i]，则 π[i] = j + 1
- `2:42` i = 4：j = 1 时 s[2] = b 不等于 s[4] = c，跳到 j = 0 也不等，π[4] = 0。
- `2:49` i = 5、6、7：每次 s[j + 1] 都和 s[i] 相等，j 一路加一，π = 1, 2, 3。
- `2:57` i = 8：j = 3，比较 s[4] = c 和 s[8] = b，不相等，失配。j 跳到 π[3] = 1——前 3 个字符的最长 border。
- `3:08` j = 1：s[2] = b 等于 s[8]，匹配成功，π[8] = 2。
  - 板书：π = 0 0 1 0 1 2 3 2

## 为什么是 O(n)：j 的涨落

- `3:20` 里面有个 while 循环，会不会很慢？看 j 的变化：每处理一个字符，j 最多 +1；每跳一次失配链，j 至少 −1。
- `3:31` j 始终 ≥ 0，所有的“+1”合起来不超过 n，所以所有的“下跳”合起来也不超过 n。整个计算 O(n)。
  - 板书：j 每步最多 +1、每跳至少 −1、且 j ≥ 0 → 总跳数 ≤ n，O(n)

## 匹配：同一条失配链

- `3:47` 用 π 在文本里找 abacabab。j 表示“模式串的前 j 个字符已经和文本对上”。前 7 个字符一路对上。
- `3:58` 文本第 8 个字符 c 和模式第 8 个字符 b 失配。朴素做法右移一格从头比；KMP 让 j 跳到 π[7] = 3。
- `4:08` 相当于模式串右移 7 − 3 = 4 格：已经对上的 abacaba 里，最长 border aba 还对着文本，不用重比。
  - 板书：失配：j ← π[j]，相当于右移 j − π[j] 格
- `4:19` 会不会漏掉移动 1～3 格的位置？如果移 d 格能成功，abacaba 就有一个长度为 7 − d 的 border，比 π[7] 还长——矛盾。
  - 板书：不会漏：移得更少就意味着更长的 border
- `4:31` 继续比下去，文本第 5～12 位与模式串完全匹配。文本里每个字符只让 j 加一次，匹配同样是 O(n + m)。
  - 板书：出现位置：5；匹配 O(n + m)
