## 讲了什么

**第一章 什么是外代数**

1. 面积的代数：两个向量张成的平行四边形，拉伸、剪切、压扁、翻转时“有向面积”怎么变，读数实时显示。
2. 三条规则：双线性、结合律、v∧v = 0。由此推出反交换 w∧v = −v∧w，以及“线性相关 ⟺ 楔积为 0”。
3. k-向量（三维动画）：有向线段、有向平面块、有向体积；2-向量只记得平面、面积和绕行方向，形状无关紧要；三维里四个向量的楔积必为 0。
4. 基底与维数：Λᵏ(ℝⁿ) 的维数是 C(n,k)（帕斯卡三角），最高次只有一维；打乱基向量的顺序，每交换一次变一次号——排列的符号 sgn(σ) 自己冒出来。
5. 第一次计算：展开 (a e₁ + c e₂)∧(b e₁ + d e₂) 得到 ad − bc；三维里 u∧v 的系数就是叉积，u∧v∧w 就是混合积。

**第二章 行列式从哪里来**

1. 线性变换作用在单位正方形上（剪切、镜像、压扁），面积倍数实时显示；定义 Te₁∧⋯∧Teₙ = (det T) e₁∧⋯∧eₙ——只用到“Λⁿ 是一维的”。
2. 推导莱布尼茨公式：3 阶的 27 项里下标重复的 21 项炸掉，剩下 3! = 6 项，按交换次数配上符号；推广到 n 阶。
3. 性质：交换两列变号、两列相同为 0、倍加不变、三角矩阵、可逆判据，每条一行证明；乘法公式 det(ST) = det S · det T 的完整推导。
4. 克莱默法则：把第 i 列换成 b 再楔起来，j ≠ i 的项全部消失；再用平行四边形沿 a₂ 滑动的动画看几何意义。
5. 拉普拉斯展开：把第一列单独拿出来，(−1)^{i−1} 来自把 eᵢ 移回原位的交换次数；三阶的例子；把楔积从第 k 列处切开得到广义拉普拉斯展开。

**第三章 一行证明的定理们**（直接证明都很费劲，在外代数里各是一两行）

1. Λᵏ A 的矩阵元是 k 阶子式（复合矩阵），Λᵏ(AB) = Λᵏ A Λᵏ B 推出“子式的乘法公式”；Λᵏ A 的特征值是 A 的特征值任取 k 个相乘。
2. 柯西–比内公式：一维 → C(n,m) 维 → 一维的“通道图”；推论拉格朗日恒等式和柯西–施瓦茨不等式。
3. 面积的勾股定理（三维动画）：平行四边形面积² = 三个坐标面上影子面积的平方和（格拉姆行列式 + 柯西–比内）；直角四面体的德古阿定理。
4. 特征多项式：(e₁ + tAe₁)∧⋯∧(eₙ + tAeₙ) 的 2ⁿ 种选法，tᵏ 的系数是 k 阶主子式之和 = tr Λᵏ A = 特征值的初等对称多项式。
5. 西尔维斯特恒等式 det(Iₘ + AB) = det(Iₙ + BA)：关键只是 tr(XY) = tr(YX)；推论秩一修正公式、AB 与 BA 的非零特征值相同。画面里的例子（2 阶和 4 阶都等于 33）是真算的。
6. 普吕克关系：二维平面 ↔ 可分解的 2-向量，ω∧ω = 0 展开得 p₁₂p₃₄ − p₁₃p₂₄ + p₁₄p₂₃ = 0；反例 e₁∧e₂ + e₃∧e₄。
7. 空间直线的普吕克坐标（三维动画）：(d; m = P × d)，直线怎么动，画面上实时计算的 d·m 都是 0；克莱因二次曲面。
8. 微分形式：dx∧dy = r dr∧dθ（极坐标的 r 就是雅可比行列式），一般的换元公式；牛顿–莱布尼茨、格林、高斯、斯托克斯合成 ∫_M dω = ∫_∂M ω。

## 画面与声音

- 深色霓虹风格：合成器浪潮式的透视网格、发光的向量和公式、粒子爆散、故障风标题、HUD 式的四角框；成片编码时再加一层全画面辉光（`build.py` 里的 `BLOOM`）。
- 配乐（`src/music.py`）：120 BPM 的合成器浪潮，超级锯齿波和弦铺底、脉冲贝斯、十六分音符琶音（乒乓延迟）、旋律和鼓组，全部用 numpy 现场合成。
  讲推导的段落用低档（每 16 小节还留 4 小节退一档“喘口气”），开场的公式快闪和尾声用满档。
- **画面和音乐是对齐的**：每个场景的时长都补齐到整小节，重要的公式出场卡在拍点上，场景里记下的重音时刻（`build/cues/*.json`）在配乐里对应一声冲击或闪光音。

## 怎么重新生成

用 [Manim Community](https://www.manim.community/)（0.22.1）画动画，ffmpeg 合成。需要 LaTeX（`texlive-latex-extra`、`texlive-fonts-recommended`、`texlive-science`、`dvisvgm`）、
思源黑体（`fonts-noto-cjk`）、`libcairo2-dev`、`libpango1.0-dev`。英文标题用的 Orbitron 字体由 `fonts.py` 从 Google Fonts 下载。

```bash
cd src
python -m venv .venv && .venv/bin/pip install manim scipy "pillow<13"
.venv/bin/python fonts.py                  # 下载 Orbitron 到 build/fonts/
.venv/bin/python build.py render           # 1080p60 渲染全部 23 个场景（4 个并行，大约一小时）
.venv/bin/python build.py music            # 按场景时长和重音表合成配乐（build/music.wav）
.venv/bin/python build.py final            # 拼接、辉光、混音、章节标记，输出三集
```

- 低清预览：`build.py render -ql 场景名…`，再 `build.py final -ql 1`（只合成上集）。只渲染一个场景也可以直接 `manim -ql --media_dir ../build/media ch2.py Leibniz`。
- `build.py final --full` 额外输出一个完整版（文件较大，没有放进仓库）；`--crf=26` 之类可以调画质和体积。
- 渲染缓存、配乐、字体都在 `build/`，不提交。
