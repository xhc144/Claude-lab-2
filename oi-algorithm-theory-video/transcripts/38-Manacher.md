## 插入分隔符，统一奇偶

- `0:24` 回文有奇数长（中心是一个字符）和偶数长（中心在两个字符之间）两种。在每两个字符之间、以及两端插入一个分隔符 #，两种就统一了。
  - 板书：T = # s₁ # s₂ # … # sₙ #：奇偶回文都以某个位置为中心
- `0:39` T 里每个回文都以某个位置为中心、两边对称；中心在字母上对应 s 的奇回文，中心在 # 上对应偶回文。
- `0:50` 记 p[i] 为 T 中以 i 为中心的回文半径（不含中心，向一边延伸的格数）。它恰好等于 s 中对应回文的长度。
  - 板书：p[i] = 以 i 为中心的回文半径 = 对应 s 中回文的长度

## 朴素：每个中心向外扩

- `1:07` 以位置 7（字母 c）为中心，两边一格一格比较，相同就扩大半径。
- `1:15` 扩到半径 7 后两端不同（红框），p[7] = 7：s 中有长度 7 的回文 abacaba。
- `1:23` 每个中心都这样扩，全是同一个字母的串（aaaa…）要 O(n²)。浪费在哪？大回文里面的小回文，左右两边是镜像的，算了两遍。
  - 板书：朴素：O(n²)；大回文内部左右对称，信息被重复计算

## 镜像：对称位置的答案可以复用

- `1:42` 从左到右算 p，同时记住“右端点最远”的那个回文：中心 C，右端 R = C + p[C]，左端 L = 2C − R。
  - 板书：维护右端点最远的回文 [L, R]，中心 C
- `1:52` i = 9 在大回文 [0, 14]（中心 7）里面。它的镜像位置 j = 2C − i = 5，p[5] = 1。
- `2:01` 大回文内部左右对称：j 周围长什么样，i 周围就长什么样。j 的回文完全落在大回文里（p[j] < R − i），所以 p[i] 一定恰好等于 p[j]。
  - 板书：i < R 时，镜像 j = 2C − i；p[j] < R − i ⇒ p[i] = p[j]
- `2:15` i = 11：镜像 j = 3，p[3] = 3，恰好碰到大回文的边界（R − i = 3）。边界以外的字符大回文管不着，只知道 p[i] ≥ 3。
  - 板书：p[j] = R − i：只知道 p[i] ≥ R − i，要继续向外扩
- `2:28` 从半径 3 接着往外比：又扩了 2 格，p[11] = 5。右端点推进到 16，它成为新的“最右回文”。
- `2:38` i = 15：镜像 j = 7，p[7] = 7，比 R − i = 1 大。这时 p[i] 恰好就是 R − i = 1，不用扩。为什么？
- `2:48` 再扩一格要比较 T[17] 和 T[13]。T[13] 关于 C 镜像、再关于 j 镜像，等于 T[5]；而大回文停在 [6, 16]，正是因为 T[5] ≠ T[17]。
  - 板书：p[j] > R − i ⇒ p[i] = R − i（两次镜像得到矛盾）
- `3:01` 最大的 p 是 p[7] = 7，对应最长回文子串 abacaba。绿色的格子都是直接从镜像抄来的，没有做任何比较。
  - 板书：p[i] 的初值 = min(p[j], R − i)；只有等于 R − i 或 i ≥ R 时才扩

## 为什么是线性的

- `3:16` 复用镜像是 O(1)。真正花时间的是向外扩的比较。注意：只有初值碰到了 R（或者 i 在 R 之外）时才需要扩。
- `3:28` 这时每扩成功一格，i 的回文右端就超出原来的 R 一格，R 随之更新为更右的位置。R 只增不减，最多到 |T| = 2n + 1。
  - 板书：每次成功扩展都让 R 右移一格；R ≤ 2n + 1 ⇒ 扩展总次数 O(n)
- `3:41` 每个 i 最多再有一次失败的比较。所以总共 O(n)——和 KMP 的“j 只增不减”是同一种势能论证。
  - 板书：每个 i 至多一次失败比较；总 O(n)
