## ax + by 能凑出哪些数

- `0:23` 先看一个问题：用 30 和 12，允许乘任意整数（可以是负数）再相加，能凑出哪些数？
- `0:33` 凑出来的恰好是 6 的所有倍数，一个不多、一个不少。6 正是 gcd(30, 12)。
  - 板书：裴蜀定理：{ax + by} = gcd(a, b) 的所有倍数
- `0:41` 为什么？a、b 都是 g = gcd(a, b) 的倍数，所以 ax + by 一定是 g 的倍数。反过来要说明 g 本身能凑出来。
- `0:52` 设 d 是能凑出的最小正数。a 除以 d 的余数 = a − ⌊a/d⌋·d 也能凑出，且比 d 小，只能是 0；所以 d 整除 a，同理整除 b。d 是公因数，又是 g 的倍数，只能 d = g。
  - 板书：最小的正 ax + by 整除 a、b ⇒ 它就是 gcd

## 辗转相除，再倒着回代

- `1:13` 求 gcd(99, 78)：gcd(a, b) = gcd(b, a mod b)，一直除到 b = 0。表格每一行是一步。
  - 板书：gcd(a, b) = gcd(b, a mod b)；b = 0 时 gcd = a
- `1:22` 最后一行 b = 0，gcd = 3。现在要找 x、y 使 99x + 78y = 3。从最后一行往上构造。
- `1:31` 最后一行：3·1 + 0·0 = 3，取 x = 1，y = 0。
- `1:37` 假设下一行已经有 b·x′ + (a mod b)·y′ = g。把 a mod b = a − ⌊a/b⌋·b 代进去整理：a·y′ + b·(x′ − ⌊a/b⌋·y′) = g。
  - 板书：x = y′，y = x′ − ⌊a/b⌋ · y′（x′, y′ 是下一行的解）
- `1:48` 例：这一行 a = 15，b = 6，下一行解是 (0, 1)，于是 x = 1，y = 0 − 2·1 = -2。
- `1:57` 回到第一行：x = -11，y = 14。验算：99·(-11) + 78·14 = -1089 + 1092 = 3。
  - 板书：99·(-11) + 78·14 = 3
- `2:05` 这就是扩展欧几里得：和辗转相除同样的 O(log min(a, b)) 步，顺便求出一组 x、y。

## 全部的解

- `2:18` 一组解有了，其他解呢？两组解相减：a(x − x₀) = −b(y − y₀)。两边除以 g，a/g 与 b/g 互素，所以 b/g 整除 x − x₀。
  - 板书：通解：x = x₀ + k·b/g，y = y₀ − k·a/g（k 为任意整数）
- `2:30` 这里 b/g = 26，a/g = 33：x 每次加 26，y 每次减 33，都满足 99x + 78y = 3。
- `2:39` 常要的是最小正整数解：x = ((x₀ mod 26) + 26) mod 26 = 15（结果是 0 时取 26）。
  - 板书：最小非负 x：(x₀ mod (b/g) + b/g) mod (b/g)
- `2:48` 一般的 ax + by = c：g 不整除 c 就无解；整除时，把上面的解乘以 c/g 即可。
  - 板书：ax + by = c 有解 ⇔ g | c；解 = (c/g) × 上面的解

## 同余方程与逆元

- `3:00` ax ≡ c (mod m) 的意思是 ax − c 是 m 的倍数，即存在整数 y 使 ax + my = c。它就是上面的方程。
  - 板书：ax ≡ c (mod m) ⇔ ax + my = c
- `3:10` 所以：有解 ⇔ gcd(a, m) 整除 c；解在模 m/gcd(a, m) 意义下唯一，模 m 意义下有 gcd(a, m) 个。
  - 板书：有解 ⇔ gcd(a, m) | c；模 m 下有 gcd(a, m) 个解
- `3:20` 特别地，ax ≡ 1 (mod m) 的解叫 a 的逆元，有逆元 ⇔ gcd(a, m) = 1。例：7 模 26 的逆元，用扩展欧几里得解 7x + 26y = 1。
- `3:32` 得到 x = -11，调整到 0～25：逆元是 15。验算 7 × 15 = 105 ≡ 1 (mod 26)。
  - 板书：逆元存在 ⇔ gcd(a, m) = 1；例：7⁻¹ ≡ 15 (mod 26)
- `3:40` 模数是素数 p 时，也可以用费马小定理：a⁻¹ ≡ aᵖ⁻² (mod p)。扩展欧几里得的好处是模数不必是素数。

## 手推 / 建模题

- `3:56` 先别急着看答案：按暂停，在纸上推一推。
- `4:21` (1) 辗转相除：gcd(21, 15) = 3，3 整除 9，有解。回代得 21·(-2) + 15·3 = 3，乘以 3：x₀ = -6，y₀ = 9。
- `4:32` 通解 x = -6 + 5k。最小正整数解 x = 4，此时 y = -5：21·4 + 15·(-5) = 9。
  - 板书：(1) 一组解 (-6, 9)；最小正 x = 4，y = -5
- `4:40` (2) gcd(8, 14) = 2 整除 6，有 2 个解。两边和模数同除以 2：4x ≡ 3 (mod 7)，4 的逆元是 2，x ≡ 6 (mod 7)。
- `4:51` 回到模 14：x ≡ 6 或 13 (mod 14)。验算 8 × 6 = 48，8 × 13 = 104，除以 14 都余 6。
  - 板书：(2) x ≡ 6、13 (mod 14)
