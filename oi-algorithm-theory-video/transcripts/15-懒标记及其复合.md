## 懒标记在做什么

- `0:27` 区间修改如果把每个叶子都改一遍，一次就是 O(n)。懒标记的想法：修改区间被拆成 O(log n) 个结点，只在这些结点上记一笔。
  - 板书：区间修改：只在 O(log n) 个结点上打标记
- `0:41` 这一笔叫标记，含义是“这个结点下面的所有元素，都还欠着这个操作”。结点自己的信息（和）立刻更新，儿子先不动。
  - 板书：标记 = 子树里所有元素“还欠着”的操作；结点自己的和已更新
- `0:54` 以后访问到它的儿子时，再把标记“下传”给两个儿子。于是有两个问题：标记怎样立刻更新结点的和？新旧标记怎样合并成一个？
  - 板书：问题一：标记如何更新结点信息？　问题二：新旧标记如何合并？

## 把标记看成函数

- `1:11` 只有区间加时，标记是“加了多少”：两次加 3、加 5 合成加 8。和的更新：和 += 加的数 × 区间长度。
  - 板书：只有加：标记 = +b；合并：b1 + b2；和 += b × len
- `1:22` 现在既有乘又有加。一串操作 ×2、+3、×5、+1 作用在 x 上，结果总是 a·x + b 的形式：
- `1:32` 所以把标记写成一个函数 f(x) = a·x + b（先乘 a，再加 b）。任意多次乘、加复合起来，还是这种形式——这个形式对复合是封闭的。
  - 板书：标记 = 函数 x → a·x + b（先乘后加）
- `1:45` 问题一：标记作用在区间和上。区间里每个数都变成 a·x + b，和就变成 a·和 + b·长度。只用到和与长度，O(1)。
  - 板书：和 → a·和 + b·len
- `1:58` 问题二：结点原有标记 (a1, b1)，又来了新操作 (a2, b2)。先做旧的再做新的：a2(a1·x + b1) + b2 = (a1a2)·x + (a2b1 + b2)。
  - 板书：复合：(a1, b1) 再 (a2, b2) = (a1a2, a2b1 + b2)
- `2:11` 顺序很重要：先 ×2 再 +3 是 2x + 3，先 +3 再 ×2 是 2x + 6。新标记必须作用在旧标记“之后”。
  - 板书：顺序不能反：×2 后 +3 ≠ +3 后 ×2
- `2:21` 为什么不用“先加后乘” a·(x + b) 的形式？在它后面再加 c 会变成 a·(x + b + c/a)，出现除法。在取模或整数下就麻烦了。
  - 板书：“先加后乘”形式复合要做除法 → 选“先乘后加”

## 一步步看标记的变化

  - 板书：标记 (×a, +b)：和 → a·和 + b·len
  - 板书：复合：(a1, b1) 再 (a2, b2) = (a1a2, a2b1 + b2)
- `2:41` 例子：a = 1, 2, 3, 4。操作一：整个区间 ×2。[1, 4] 正好是根，只在根上打标记 (×2, +0)，根的和变成 2 × 10 = 20。
- `2:53` 儿子们的和还是旧的 3 和 7——它们“欠着”根上的 ×2。这没关系，因为只要不访问它们，就没人看到旧值。
- `3:04` 操作二：[1, 2] 加 3。要走到 [1, 2]，先把根的标记下传：两个儿子的和各自 ×2，标记 (×2, +0) 复合到它们原来的空标记上。
  - 板书：下传：儿子的和用父标记更新，父标记复合到儿子标记之后，父标记清空
- `3:18` 然后给 [1, 2] 加 3：和 = 6 + 3 × 2 = 12；标记复合：(×2, +0) 之后再 (×1, +3)，得到 (×2, +3)。根的和重新合并：12 + 14 = 26。
- `3:30` 操作三：查询 a[1]。走到叶子前，[1, 2] 的标记 (×2, +3) 下传：1 → 2×1+3 = 5，2 → 2×2+3 = 7，和 5 + 7 = 12，正好对上。
- `3:43` 右边的 [3, 4] 一直没被访问，它的标记 (×2, +0) 还挂着，叶子 3、4 里还是旧值——但它们的真实值 6、8 已经体现在 [3, 4] 的和 14 里了。

## 下传为什么是对的

- `4:01` 关键是一个不变式：在任何一条从根到叶子的路径上，越深的标记越旧。
  - 板书：不变式：根到叶子的路径上，越深的标记越旧
- `4:09` 原因：要给某个结点打新标记，必须先从根走下来，沿路把祖先的标记都下传掉。所以新标记打下去时，它上面没有更老的标记。
- `4:23` 于是叶子的真实值 = 把路径上的标记从深到浅依次作用上去。下传只是把父亲的标记接在儿子标记的后面，作用顺序没有改变。
  - 板书：真实值 = 路径上的标记从深到浅依次作用；下传不改变顺序
- `4:37` 能用懒标记的一般条件有三条：
  - 板书：① 标记对复合封闭（两次操作能合成一个标记）
  - 板书：② 标记能直接更新结点信息（不看儿子）
  - 板书：③ 先合并再作用 = 先作用再合并
- `4:42` 第三条是说：对父亲的和作用标记，等于对两个儿子分别作用再相加：a(L + R) + b(lenL + lenR) = (aL + b·lenL) + (aR + b·lenR)。
- `4:55` 反例：区间开平方根，区间求和。√a + √b ≠ √(a + b)，只知道区间和，算不出开方以后的和——条件②不成立，不能打懒标记。
  - 板书：反例：区间开方 + 区间和（√a + √b ≠ √(a+b)）✗

## 手推 / 建模题

- `5:12` 先别急着看答案：按暂停，在纸上推一推。
- `5:37` (1) 能。赋值为 c 就是 x → 0·x + c，即 (a, b) = (0, c)。乘 0 把旧值完全清掉。
  - 板书：(1) 赋值 c = (×0, +c)
- `5:46` (2) 按复合公式：(3, 1) 再 (0, 5) = (3×0, 0×1 + 5) = (0, 5)——旧标记被清空，符合直觉。
  - 板书：(×3, +1) 再 (×0, +5) = (×0, +5)
- `5:56` 再 (1, 2)：(0×1, 1×5 + 2) = (0, 7)。意思是“整段都变成 7”，正确。
  - 板书：再 (×1, +2) = (×0, +7)：整段变成 7
- `6:03` 把标记看成函数、用函数复合来合并，三种操作统一成了一种，下传的正确性也是同一个论证。
