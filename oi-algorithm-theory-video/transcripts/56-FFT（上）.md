## 系数表示与点值表示

- `0:26` 多项式 A(x) = a₀ + a₁x + … + aₙ₋₁xⁿ⁻¹ 可以用系数 (a₀, …, aₙ₋₁) 表示；也可以用它在 n 个不同点上的取值表示——n 个点唯一确定一个 n − 1 次多项式。
  - 板书：系数表示 (a₀, …, aₙ₋₁) ↔ 点值表示 (A(x₀), …, A(xₙ₋₁))
- `0:41` 乘积 C = A · B 在每个点的取值，就是 A、B 在这个点取值的乘积：点值表示下乘法只要逐点相乘，O(n)。
- `0:52` C 是 2 次多项式，需要 3 个点才能确定。从这 3 个值反推系数，正好是 C(x) = 3 + 7x + 2x²。
  - 板书：点值表示下乘法 O(n)；点数要 ≥ 乘积的次数 + 1
- `1:02` 于是乘法可以这样做：系数 → 点值（求值）→ 逐点相乘 → 点值 → 系数（插值）。可是朴素求值每个点 O(n)，n 个点又是 O(n²)。关键在于挑一组特别的点。
  - 板书：系数 → 点值 → 相乘 → 系数；瓶颈在两头的转换

## 单位根：平方后个数减半

- `1:23` 复数 ω = cos(2π/n) + i·sin(2π/n) 叫 n 次单位根：在单位圆上，从 1 出发转 1/n 圈。它的各次幂 ω⁰, ω¹, …, ωⁿ⁻¹ 把圆周 n 等分。
  - 板书：ωₙ = e^{2πi/n}；ωₙᵏ（k = 0..n−1）把单位圆 n 等分
- `1:36` 乘以一个单位圆上的复数，就是转一个角度。所以 ωᵏ 的平方，角度翻倍。
  - 板书：复数乘法：长度相乘、角度相加
- `1:45` 把 8 个点全部平方：角度翻倍，ωᵏ 和 ω^11.0 落到同一个点上。8 个点只剩 4 个，正好是 4 次单位根。
  - 板书：(ωₙᵏ)² = ω_{n/2}ᵏ，且 ωₙ^{k+n/2} = −ωₙᵏ：平方后个数减半
- `1:55` 另一面：ω^{k+n/2} = −ωᵏ，正好在 ωᵏ 的对面。这两个性质就是 FFT 能分治的原因。

## 奇偶拆分：一次算两个点

- `2:09` 把 A(x) 的系数按下标奇偶分开：A(x) = E(x²) + x · O(x²)，E 是偶数项系数组成的多项式，O 是奇数项。
  - 板书：A(x) = E(x²) + x · O(x²)
- `2:20` 代入 ωᵏ 和它对面的 −ωᵏ：两者平方都是 ω²ᵏ，所以只要知道 E、O 在 ω²ᵏ 处的值，就能同时得到两个点：
  - 板书：A(±ωᵏ) = E(ω²ᵏ) ± ωᵏ · O(ω²ᵏ)
- `2:32` 而 E、O 要在 n/2 个点（n/2 次单位根）上求值——规模减半的同一个问题，递归下去。
- `2:41` T(n) = 2T(n/2) + O(n)，所以 T(n) = O(n log n)。这就是快速傅里叶变换（FFT）。n 要补成 2 的幂。
  - 板书：T(n) = 2T(n/2) + O(n) = O(n log n)；n 补到 2 的幂

## 蝴蝶：把递归摊平

- `2:56` 把递归展开：最底层是单个系数，往上每一层把两半合并。n = 4 时，叶子的顺序是 a₀、a₂、a₁、a₃——下标的二进制翻转后的顺序。
  - 板书：叶子顺序 = 下标二进制翻转（位逆序）
- `3:10` 第一层：每两个合并。E(y) = a₀ + a₂y 在 y = ±1 的值是 a₀ ± a₂；O 同理是 a₁ ± a₃。
- `3:19` 第二层：A(ωᵏ) = E(ω²ᵏ) + ωᵏO(ω²ᵏ)，A(−ωᵏ) 换成减号。每一对交叉的线像一只蝴蝶——这就是“蝴蝶操作”。
  - 板书：每层 n/2 个蝴蝶，共 log n 层；可以原地、非递归实现
- `3:31` 每层 n/2 个蝴蝶，log n 层。按位逆序排好系数后，从下往上原地合并，不需要递归。下一集讲怎样从点值变回系数。

## 手推 / 建模题

- `3:48` 先别急着看答案：按暂停，在纸上推一推。
- `4:13` (1) 偶数项：E(y) = 1 + 3y；奇数项：O(y) = 2 + 4y。
  - 板书：(1) E(y) = 1 + 3y，O(y) = 2 + 4y
- `4:19` (2) E(1) = 4，E(−1) = −2；O(1) = 6，O(−1) = −2。A(1) = 4 + 6 = 10，A(−1) = 4 − 6 = -2；A(i) = E(−1) + i·O(−1) = −2 − 2i，A(−i) = −2 + 2i。
- `4:33` 验算 A(i) = 1 + 2i + 3i² + 4i³ = 1 + 2i − 3 − 4i = −2 − 2i。
  - 板书：(2) A(1) = 10，A(i) = −2 − 2i，A(−1) = -2，A(−i) = −2 + 2i
